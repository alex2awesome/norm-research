Documentation




There are seven main components of the documentation of Magma:



    

  • 
J. Cannon and C. Playoust: First Steps in Magma, 16 pages;

  • 
J. Cannon and C. Playoust: An Introduction to Magma, 450 pages;

  • 
W. Bosma and J. Cannon: Handbook of Magma Functions, 900 pages;

  • 
W. Bosma, J. Cannon et al.: Solving Problems with Magma, 100 pages;

  • 
The Magma HTML Help Document;

  • 
The Online Help System.

  • 
The Magma Home Page.




"First Steps in Magma" is a very first guide to {\magma},
suitable for use in the early stages of learning the system.


The Magma Introduction does not assume
any previous knowledge of programming languages
or specialist knowledge of computer algebra,
and provides a gentle introduction to the system.


The Magma Handbook gives
complete documentation for every language and environmental feature.


The problem-solving book contains extended examples of Magma code,
illustrating how to solve some mathematically-hard problems using Magma.


The Online Help System offers a variety of levels of information, and, in
particular, enables access to the Handbook descriptions of all functions
and operators.


The Magma HTML Help Document contains an overview of Magma based on the
Overview nodes of the Magma Online Help System, together with an HTML
version of the whole of the Magma Handbook.


The Magma Home Page can be found at
<URL:http://www.maths.usyd.edu.au:8000/comp/magma/Overview.html>.
