Errata for Linear Algebra by Serge Lang, 3rd edition

This is a list of errata for the third edition of the book "Linear Algebra" by Serge Lang, published by Springer. In this list, the line counts include lines consisting of an equation. Negative line counts refer to lines counted from the bottom of the page.

Page 4 line 2: elements should be element

Page 11 line 21: $\ell$ should be 1

Page 15 line 2: functons should be functions

Page 19 line 7: maxmal should be maximal

Page 64 line 9: dimensison should be dimension

Page 65 line -5: dimensison should be dimension

Page 70 line -2: In question 8(a), the map given is not invertible. For example, $L(1,1,-1)=0$.

Page 79 line -6: be definition should be by definition

Page 104 line 3: Chapter II, §3 should be Chapter I, §3. I cannot see where this result is given in Chapter I, so I assume §3 was meant, but it certainly doesn't appear in Chapter II, §3 which is about matrix multiplication. It may be that Chapter I, §2 was the intention.
