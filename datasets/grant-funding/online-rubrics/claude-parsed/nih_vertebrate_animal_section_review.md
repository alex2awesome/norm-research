# NIH Vertebrate Animals Section (VAS) - Review Criteria

## Four Required Review Criteria

Reviewers evaluate the involvement of live vertebrate animals according to four criteria:

### 1. Description of Procedures Involving Animals
Must include:
- Species
- Strains
- Ages
- Sex
- Total number of animals to be used
- Concise description of the proposed procedures involving live vertebrate animals
- Routine procedures (housing, husbandry) generally not required to be described

### 2. Justifications for Use of Animals
- Why this species and strain are appropriate for the proposed research
- Why research goals cannot be accomplished using alternative models:
  - Computational models
  - Human studies
  - Invertebrate models
  - In vitro / cell culture
  - Existing data/biospecimens
- Justification for the appropriateness of the species proposed
- Justification for the number of animals (minimum needed for valid statistical conclusions)

### 3. Interventions to Minimize Discomfort, Distress, Pain, and Injury
- Description of analgesia, anesthesia, sedation
- Palliative care
- Methods of restraint
- Surgical procedures
- Plan for monitoring animals during/after procedures
- Humane endpoints (criteria for early removal from study)

### 4. Justification for Method of Euthanasia
- Required only if euthanasia method is NOT consistent with the AVMA Guidelines for the Euthanasia of Animals
- If using AVMA-consistent method, simply state so
- If using alternative method, must provide scientific justification

## Review Standards
An application will be rated **UNACCEPTABLE** if all required items are not addressed adequately or are found inappropriate.

## Additional Requirements

### IACUC Approval
- Institutional Animal Care and Use Committee (IACUC) approval required before funds can be released
- Animals must be procured from approved sources
- Care must follow Guide for the Care and Use of Laboratory Animals

### OLAW Assurance
- Performing institution must have an Animal Welfare Assurance approved by NIH's Office of Laboratory Animal Welfare (OLAW)
- Must have IACUC composition meeting federal requirements

## Worksheet for Reviewers
NIH provides a Vertebrate Animal Section worksheet to standardize reviewer evaluation across the four criteria.

## Special Considerations
- Field studies have additional reporting requirements
- Studies using endangered species require permits
- Studies using non-human primates have heightened review
- USDA-regulated species (most mammals) have additional oversight
