# WikiHow — How to Write a Grant Proposal

WikiHow's "Write a Grant Proposal" article has been edited by hundreds of contributors and verified by editorial team. Generic but widely-read entry-level guide.

## WikiHow's Step Structure

### Step 1: Understand the Grant Application Process
- Identify funders aligned with your project
- Read the RFP/RFA carefully
- Note deadlines, page limits, format requirements
- Contact program officer if questions

### Step 2: Develop Your Project Concept
- Define the problem clearly
- Articulate your goals
- Identify outcomes
- Connect to funder's priorities

### Step 3: Write a Cover Letter
- Brief introduction of organization/PI
- Statement of need
- Brief project description
- Amount requested
- Contact information

### Step 4: Write the Executive Summary / Project Summary
- 1-page overview
- Problem, solution, impact
- Briefly mentioned: organization, budget, timeline
- Last to write, first to read

### Step 5: Write the Statement of Need
- Document the problem with data
- Cite credible sources
- Show urgency
- Connect to funder's priorities

### Step 6: Describe Your Project
- Goals and objectives
- Methodology
- Timeline with milestones
- Personnel and roles
- Expected outcomes

### Step 7: Develop the Budget
- Personnel costs (salaries, benefits)
- Direct costs (supplies, equipment, travel)
- Indirect costs (overhead, if allowed)
- Justify each line item

### Step 8: Include Evaluation Plan
- How you'll measure success
- Specific metrics
- Data collection methods
- Reporting plan

### Step 9: Add Supporting Documents
- Letters of support
- IRB/IACUC approvals
- Organizational documents (for nonprofits)
- CVs/biosketches
- References

### Step 10: Edit and Submit
- Multiple drafts
- Outside reader feedback
- Format check
- Submit before deadline

## WikiHow's Generic Best Practices

### Clarity and Concision
- Define jargon
- Active voice
- Topic sentences
- Bullet points where appropriate

### Alignment with Funder
- Match funder's language
- Reference funder's priorities explicitly
- Cite funder's funded portfolio where relevant
- Match format requirements exactly

### Evidence-Based Approach
- Cite credible data sources
- Quantify problem and impact
- Show research-based methodology
- Include evaluation plan

### Professional Presentation
- No typos
- Consistent formatting
- Page numbers
- Section headings
- White space

## Implicit WikiHow Rubric

### What Wins (Per WikiHow)
1. Clear statement of need with data
2. Aligned with funder's priorities
3. Specific goals and objectives
4. Realistic methodology
5. Budget aligned with scope
6. Evaluation plan
7. Letters of support
8. Professional presentation
9. Personnel with relevant expertise
10. Sustainability plan (for nonprofit grants)

### Common Mistakes WikiHow Lists
1. Vague problem statement
2. Mismatched funder priorities
3. Unrealistic budget
4. No evaluation plan
5. Missing required documents
6. Format violations
7. Late submission
8. Generic letters of support
9. Personnel mismatch with project
10. No sustainability plan
