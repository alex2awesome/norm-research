# NIH Data Management and Sharing (DMS) Plan

## Overview
The NIH Policy for Data Management and Sharing (DMS Policy) went into effect January 25, 2023. NIH-funded researchers must submit a plan outlining how scientific data from their research will be managed and shared within their funding application.

## Updated Requirements (2026)
NIH released NOT-OD-26-046 with Updated Elements of an NIH Data Management and Sharing Plan. Effective for applications on or after **May 25, 2026**. The new elements are mostly yes/no questions plus a table listing data types and repositories.

## Six Plan Elements

### Element 1: Data Type
- Types of scientific data to be generated
- Estimated amount of data
- Data types subject to sharing

### Element 2: Related Tools, Software and/or Code
- Tools needed for accessing or manipulating data
- Open vs. proprietary
- Sustainability of any custom-developed tools

### Element 3: Standards
- Data and metadata standards to be applied
- Common data elements
- File formats compatible with standards

### Element 4: Data Preservation, Access, and Associated Timelines
- Repository where data will be archived
- Persistent unique identifiers (DOIs)
- Time period of data availability
- Access procedures and any restrictions

### Element 5: Access, Distribution, or Reuse Considerations
- Anticipated limitations on data sharing
- Plans for protecting privacy and confidentiality
- Whether data will be controlled access vs open

### Element 6: Oversight of Data Management and Sharing
- How compliance will be monitored
- Who is responsible for compliance
- Frequency of internal review

## Key Requirements (2026)

### Yes/No Questions
- Will there be maximum appropriate sharing of scientific data underlying peer-reviewed publications and other findings?
- Will the scientific data underlying peer-reviewed publications be shared by the time of publication or by the end of the period of performance?
- Will shared scientific data be made available for at least as long as required by applicable data repository policies and/or journal policies?

## Compliance and Management
- Once a grant is awarded, the DMS Plan becomes part of the award's terms and conditions
- NIH expects researchers and institutions to implement data management and sharing practices as described
- Compliance reviewed during regular reporting intervals (annual RPPR)
- Plan can be updated during the project

## Resources for Repositories
- NIH-recommended generalist repositories
- Domain-specific repositories (dbGaP, GEO, ClinicalTrials.gov, etc.)
- NIH supports sharing in repositories that follow FAIR principles
