About Marie Skłodowska-Curie Actions

Use this guide to learn about the different types of Marie Skłodowska-Curie Actions (MSCA) funding supports and to learn which one is most suitable for you. You can learn about how to apply and individuals can learn how to search for a job advertised by an MSCA funded project.

The information provided in this guide is a summary of the main rules and requirements.

Please note that the information in this page is indicative. For all the details about the MSCA actions and calls please refer to the Funding & Tenders Portal and the latest MSCA work programme and general annexes.
