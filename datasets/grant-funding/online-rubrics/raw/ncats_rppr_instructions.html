CTSA RPPR Questions

Find CTSA Program funding opportunities

NIH Guide notice NOT-OD-15-014 requires that all grant progress reports for the CTSA Program grant mechanisms be submitted electronically using the Research Performance Progress Report (RPPR) format. Please visit the NIH RPPR page for an overview and technical assistance for preparing and submitting reports.

Note: Download the PDF files below and open them in your computer’s PDF application (e.g., Acrobat Reader) in order to access the appendices attached to the PDF.

Read RPPR guidance for CTSA Program institutions:

  • 2026 Supporting Instructions for CTSA Program RPPRs – UM1 (PDF - 446KB) – UPDATED JANUARY 2026
  • 2026 Supporting Instructions for Research Performance Progress Reports (RPPRs) for the Clinical and Translational Science Awards (CTSA) Program UL1, KL2 and TL1 Awards (PDF - 535KB) – UPDATED FEBRUARY 2026
  • Guidance for Correcting Human Subjects Submission Validation Errors (PDF - 808KB)

Follow the NIH instructions in Section 7.4 for the K12 and T32 grant mechanisms. If you would like to use the Appendix 3: Training Progress Report template, you can download it (Word - 45KB). Use of the template is not required.
