Texas Rules

Texas Administrative Code (TAC) Texas Register Research Tips

Texas Administrative Code (TAC)

The Texas Administrative Code is a compilation of all state agency rules in Texas. It is continuously updated as rules are adopted or repealed.

Online

  • Current — Texas Administrative Code This link opens in a new window
    The current version of the Texas Administrative Code is published on the Texas Secretary of State's website.
  • 1999 – present — Texas Administrative Code: Search This link opens in a new window
    The Texas Secretary of State's TAC search feature can locate rules as they stood historically, going back to 1999.

In Print

  • 1979 – present — Texas Administrative Code This link opens in a new window
    Current print copies available at the library's reference desk. Older print copies are held in the library's archive and can be requested from a librarian.

Texas Register

The Texas Register is a weekly journal of Texas state agency rulemaking. It includes:

  • proposed, adopted, withdrawn and emergency rule actions;
  • notices of state agency review of agency rules; 
  • governor's appointments;
  • attorney general opinions; and
  • miscellaneous documents such as requests for proposals.

After rules are adopted, they are codified and published in the Texas Administrative Code.

Online

  • 1976 – present — Texas Register This link opens in a new window
    UNT's Portal to Texas History provides access to all historical versions of the Texas Register, beginning with Volume 1, No. 1 (January 6, 1976) up to within a week of the most currently released issue.
  • 1/28/2000 – present — Texas Register: Search This link opens in a new window
    The Texas Secretary of State's Office Texas Register search feature can locate entries in the Texas Register back to January 28th, 2000.
  • 1997 – present — Texas Register Indexes This link opens in a new window
    The Texas Secretary of State's Office provides Texas Register indexes starting in 1997.

In Print

  • 1976 – present — Texas Register This link opens in a new window
    Current print copies available for checkout. Older print copies are held in the library's archive and can be requested at the library's reference desk.

Research Tips

  • Administrative Law Handbook: Rulemaking This link opens in a new window
    This publication from the Texas Attorney General's Office describes Texas's rule-making process in depth.
  • Finding Texas Regulations This link opens in a new window
    This guide describes how to find information in the Texas Register and the Texas Administrative Code. It is published by Tarlton Law Library, U.T. Austin School of Law.
  • Researching Texas Law: Administrative Rulemaking & Agency Procedure This link opens in a new window
    This guide describes how to find final Texas rules as well as non-final Texas rules. It is published by the Dee J. Kelly Law Library, Texas A&M School of Law.
