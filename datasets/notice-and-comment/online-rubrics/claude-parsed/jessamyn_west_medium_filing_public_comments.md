# Get Active: How to File Public Comments on Government Actions (Jessamyn West, Medium)

A librarian's civic playbook entry on the mechanics and craft of submitting comments to Regulations.gov.

## Where to File
Go to **Regulations.gov** to submit feedback on proposed federal regulations from multiple federal agencies.

## Find Your Issue
- Browse trending regulations on the main page
- Use keyword or advanced search functions
- Check "Featured Regulations" or see which comments are closing soon
- Explore the full docket folder containing supporting documents and existing comments

## Understand the Process
"Finding the rule is only part of the process" — rules exist within docket folders containing supporting documents, metadata, and all public comments. Read those before commenting.

## Writing the Comment

**Format and Length:**
- Use the text box (5,000 character limit)
- Attach PDFs or other supporting documents if needed
- Some commenters submit only PDF attachments

**Content Strategy:**
- Use original language rather than form letters
- "Effective comments with good supporting information carry more weight than hundreds of copypasted form letters"
- If an organization poses specific questions, treat them as suggestions rather than rigid requirements

## Procedural Details
- Comments cannot be edited after submission
- You receive a tracking number as confirmation
- Personal information becomes public unless anonymity is requested
- Comments genuinely influence outcomes per agency documentation

## After Submission
Use your tracking number to follow up with the responsible agency on how your comment was considered.
