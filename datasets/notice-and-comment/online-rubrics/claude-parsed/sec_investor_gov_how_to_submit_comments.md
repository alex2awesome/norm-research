# How to Submit Comments to the SEC (Investor.gov)

## Four Primary Methods
1. **Online Comment Form** — "Submit a Comment" link on the rule/release page; attachments permitted.
2. **Email** — rule-comments@sec.gov; File Number (e.g., S7-, SR-, PCAOB-, 4-) in subject line. Accepted formats: PDF, Word, plain text. Avoid HTML, GIF, TIFF, PIF, ZIP, EXE.
3. **Paper Mail** — Secretary, 100 F Street NE, Washington, DC 20549-1090, with File Number.
4. **Feedback Flyer** (when available) — specialized webforms designed for individual investors with targeted questions.

## Key Requirements
- The SEC accepts comment letters in PDF format and other standard document types
- Avoid attachments in HTML or executable formats
- Do not include personal identifiable information

## Critical Notice
"All comments will be made available to the public." The SEC converts paper comments to PDF and posts online. When identical submissions arrive, only the first is published with a count of duplicates — meaning template campaigns are deduplicated by design.

## Additional Resources
SEC publishes an investor bulletin "Suggestions for How Individual Investors Can Comment on SEC Rulemaking" with substantive guidance.
