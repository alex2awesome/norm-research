# NeurIPS Paper Checklist Guidelines

## Overview
The checklist promotes responsible ML research by addressing reproducibility, transparency, ethics, and societal impact. Papers lacking the checklist face desk rejection.

## Submission Format Requirements
Papers must include in order: (1) submitted paper, (2) optional technical appendices, (3) NeurIPS checklist. The checklist doesn't count toward page limits.

## General Instructions
For each question, answer: yes, no, or n/a (not applicable/not available). Authors may explain answers with brief 1-2 sentence justifications. Checklist responses are visible to reviewers and published with final papers.

## The 16 Checklist Items

**1. Claims:** Main claims in abstract and introduction must accurately reflect contributions and match experimental results regarding generalization scope.

**2. Limitations:** Papers should include a dedicated limitations section addressing strong assumptions, robustness to assumption violations, scope constraints, and performance factors. Authors shouldn't fear honest limitation disclosure.

**3. Theory, Assumptions and Proofs:** If including theoretical results, state all assumptions clearly and provide complete proofs (main paper or supplemental). Include proof sketches for intuition.

**4. Experimental Result Reproducibility:** Provide reasonable reproducibility avenues appropriate to contribution type—whether through algorithm clarity, architecture description, model access, or detailed replication instructions.

**5. Open Access to Data and Code:** Include code, data, and instructions for reproducing main experimental results (supplemental or URL). While encouraged, non-inclusion isn't grounds for rejection unless central to contribution.

**6. Experimental Setting/Details:** Specify all training details including data splits and hyperparameter selection. Important details belong in main paper; full details can reside in code or supplements.

**7. Experiment Statistical Significance:** Report error bars, confidence intervals, or statistical significance tests for main claims. Clearly state variability factors and calculation methods.

**8. Experiments Compute Resource:** Disclose computer resources needed (CPU/GPU type, memory, execution time) for reproducing experiments, including total compute estimates.

**9. Code Of Ethics:** Confirm adherence to "NeurIPS Code of Ethics" and explain any necessary deviations while maintaining anonymity.

**10. Broader Impacts:** Discuss potential negative societal impacts when applicable—malicious uses, fairness concerns, privacy/security risks, and mitigation strategies.

**11. Safeguards:** Implement safeguards for high-risk model releases requiring controlled access. Make good-faith efforts toward responsible release mechanisms.

**12. Licenses:** Cite creators and respect licenses for existing assets (code, data, models). Include URLs, version numbers, and license names (e.g., CC-BY 4.0).

**13. Assets:** Document newly released assets with structured templates covering training details, limitations, licensing, and consent information.

**14. Crowdsourcing and Research with Human Subjects:** Include participant instructions, screenshots, and compensation details. Pay workers at minimum wage per Code of Ethics.

**15. IRB Approvals:** Obtain Institutional Review Board approval when required for human subjects research. Clearly state approval status without breaking anonymity.

**16. Declaration of LLM usage:** Describe LLM usage only if it's an important, original, or non-standard core methodology component—not required for writing/editing purposes.
