# ICLR 2024 Reviewer Guidelines

## Core Reviewer Responsibilities

Reviewers must ensure that evaluations are "timely and substantive" while adhering to the Code of Ethics and Code of Conduct. The role is described as "central to the program creation process."

## Key Evaluation Framework

Reviewers should address four fundamental questions:

1. What specific problem does the paper tackle?
2. Is the approach well-motivated and properly positioned in literature?
3. Do results support the claims with correctness and scientific rigor?
4. Does the work contribute "new, relevant, impactful knowledge" to the community?

## Review Structure Requirements

Reviews must include:
- Summary of paper's contributions (positive, constructive tone)
- Comprehensive lists of strengths and weaknesses
- Clear initial recommendation with key justifications
- Supporting arguments for the recommendation
- Clarifying questions for authors
- Constructive feedback for improvement

## Important Evaluation Principles

**State-of-the-art is not required.** Papers need not achieve leading results to merit acceptance; they should "convincingly demonstrate new, relevant, impactful knowledge."

**Supplementary materials** may clarify questions but aren't mandatory reading.

**Recent work standards:** Papers published within four months of submission deadline need not be cited.

## Code of Ethics Compliance

Reviewers must complete a Code of Ethics report flagging potential violations during submission and maintain engagement during discussion phases.

## Discussion and Borderline Cases

The process includes an asynchronous discussion phase where reviewers should remain "open to changing" recommendations based on author responses and peer feedback.
