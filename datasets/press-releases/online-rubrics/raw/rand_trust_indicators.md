<h1>The Trust Project Indicators</h1>
<dl class="compact website">
<dt>Website</dt>
<dd><a href="https://thetrustproject.org/">The Trust Project Indicators</a></dd>
</dl>
<p>Founded in 2016</p>
<p class="desc">The Trust Project is a collaborative initiative of several news companies that is developing standards to increase transparency in journalism. The project developed the following "Trust Indicators" as a start: Best Practices, Author/ Reporter Expertise, Type of Work, Citations and References, Methods, Locally Sourced, Diverse Voices, Actionable Feedback. News Organizations will display the indicators on their own articles.</p>

<p class="disclaimer"><em>The Trust Project Indicators is not affiliated with RAND. It was selected for this database because it fit our researchers' <a href="/research/projects/truth-decay/fighting-disinformation/methodology.html">inclusion criteria</a>. However, as of December 2020, The Trust Project Indicators is no longer being reviewed, and this page is not being updated with new data.</em></p>

<dl class="compact">
<dt>Tool type</dt>
<dd>
Codes and standards
</dd>
<dt>Status</dt>
<dd>Fully operational</dd>
<dt>Intended users</dt>
<dd>Journalists</dd>
<dt>Cost</dt>
<dd>Free</dd>
<dt>Tool focus</dt>
<dd>This tool is both content- and process-focused. It directly evaluates information (e.g., authenticating a photo), but also assesses how information is produced and disseminated.</dd>
<dt>Method or technology</dt>
<dd>Human implementation</dd>
<dt class="no-colon">Is the tool automated?</dt>
<dd>No</dd>
<dt>Founding organization</dt>
<dd>The Trust Project</dd>
<dt>Founder/primary contact</dt>
<dd>Salley Lehrman</dd>
</dl>

<h2>How is this tool working to address disinformation?</h2>
<p>This tool hopes to fight disinformation by using indicators to amplify high-quality journalism and helping users avoid lower-quality sources that may contain misinformation or disinformation.</p>

<h2>Is there a connection with tech platforms?</h2>
<p>Yes. Google, Facebook, and Bing are tech partners. The Trust Project received financial support from Google.</p>

<h2>Who is funding the tool?</h2>
<p>Craig Newmark, Democracy Fund, John S. and James L. Knight Foundation, Markkula Foundation</p>

<h2>Are there external evaluations?</h2>
<p>None found</p>
