<p>As a professional communicator, you have the potential to influence economies and affect lives. This power carries with it significant responsibilities.</p>

<p>The International Association of Business Communicators requires its members to agree to the IABC Code of Ethics. This code serves as a guide to making consistent, responsible, ethical and legal choices in all of our communications.</p>

<h3>IABC&rsquo;s Code of Ethics</h3>

<ol>
 <li><strong>I am honest.</strong> My actions bring respect for and trust in the communication profession.</li>
 <li><strong>I communicate accurate information</strong> and promptly correct any errors.</li>
 <li><strong>I obey laws and public policies</strong>; if I violate any law or public policy, I act promptly to correct the situation.</li>
 <li><strong>I protect confidential information</strong> while acting within the law.</li>
 <li><strong>I support the ideals of free speech</strong>, freedom of assembly, and access to an open marketplace of ideas.</li>
 <li><strong>I am sensitive to others</strong> cultural values and beliefs.</li>
 <li><strong>I give credit to others for their work </strong>and cite my sources<strong>. </strong></li>
 <li><strong>I do not use confidential information </strong>for personal benefit.</li>
 <li><strong>I do not represent conflicting or competing interests </strong>without full disclosure and the written consent of those involved.</li>
 <li><strong>I do not accept undisclosed gifts or payments</strong> for professional services from anyone other than a client or employer.</li>
 <li><strong>I do not guarantee results</strong> that are beyond my power to deliver.</li>
</ol>

//Slicknav close open menu items when opening another
function slicknavOpened(trigger) {
    var $trigger = $(trigger[0]);
    if ($trigger.hasClass('slicknav_btn')) {
        // this is the top-level menu/list opening.
        // we only want to trap lower-level/sublists.
        return;
    }
    // trigger is an <a> anchor contained in a <li>
    var $liParent = $trigger.parent();
    // parent <li> is contained inside a <ul>
    var $ulParent = $liParent.parent();
    // loop through all children of parent <ul>
    // i.e. all siblings of this <li>
    $ulParent.children().each(function () {
        var $child = $(this);
        if ($child.is($liParent)) {
            // this child is self, not is sibling
            return;
        }
        if ($child.hasClass('slicknav_collapsed')) {
            // this child is already collapsed
            return;
        }
        if (!$child.hasClass('slicknav_open')) {
            // could throw an exception here: this shouldn't happen
            // because I expect li to have class either slicknav_collapsed or slicknav_open
            return;
        }
        // found a sibling <li> which is already open.
        // expect that its first child is an anchor item.
        var $anchor = $child.children().first();
        if (!$anchor.hasClass('slicknav_item')) {
            return;
        }
        // close the sibling by emulating a click on its anchor.
        $anchor.click();
    });
}
