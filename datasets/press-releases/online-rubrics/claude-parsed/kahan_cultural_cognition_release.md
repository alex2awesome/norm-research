# Kahan / Cultural Cognition — release rubric for value-charged science topics

Kahan's research program shows that on culturally contested scientific topics, audiences process information through cultural-identity filters rather than pure factual evaluation. Releases that ignore this fail in their downstream effect even when picked up by media. The implications for press-release writing on contested topics are precise.

## Kahan's diagnostic claims
1. **Identity-protective cognition.** Audiences accept evidence consistent with their cultural identity and reject evidence that threatens it.
2. **Pollution of the science-communication environment.** Once a topic is "polluted" by cultural-conflict cues, neutral information processing collapses.
3. **Trusted-translator effect.** Acceptance depends on whether the messenger is culturally trusted by the recipient.
4. **Cultural framing of equivalent facts.** The same data, framed in technocratic / market / regulatory / individual-rights language, lands differently with different cultural worldviews.

## Kahan rubric criteria for releases on contested-science topics
1. **Cultural-pollution audit.** Has the topic been polluted by prior cultural-conflict framing (climate, vaccines, GMO, gun violence, race-and-genetics, AI safety)? If yes, generic release framing will trigger reactive rejection.
2. **Diverse-messenger lineup.** Does the release name and quote scientists from multiple ideologically-coded backgrounds (e.g., a libertarian-trusted source *and* a communitarian-trusted source on the same finding)? The "trusted translator" effect amplifies acceptance.
3. **Frame-pluralism.** Where possible, supply *both* a market/individualism-framed version *and* a regulatory/communitarian-framed version of the same release for differential distribution.
4. **Avoidance of culturally-coded wedge language.** Avoid lexical items that signal cultural alignment with one side ("climate denier", "anti-vaxxer", "gun nut", "libtard"). These cues collapse the trust required for unbiased reception.
5. **Emphasis on process over conclusion.** On contested topics, foregrounding scientific *method* (transparent data, pre-registration, replication) builds trust more than emphasizing the conclusion.
6. **Pre-emption of motivated counter-reasoning.** Releases on contested topics should anticipate the most plausible identity-protective objection and address it factually within the release.
7. **Trusted-institution endorsement.** Quote endorsements from institutions trusted across the cultural spectrum (e.g., NAS, military, religious bodies) when appropriate.
8. **Avoidance of moralized framing.** Kahan shows moralized framing reduces acceptance among the targeted out-group. Releases should report findings without moral verdicts on dissenters.
9. **Localized identity hooks.** Pickup increases when releases offer locally-relevant identity hooks (regional impacts, occupation-specific findings, community-led research).
10. **Replication / consensus signal where genuine.** When a finding is part of an established scientific consensus, the release should mark that explicitly (e.g., "This is consistent with the consensus view of [N] international assessments...").

## Pickup-worthiness implication
On topics free of cultural pollution, traditional pickup criteria dominate (Sumner / Yavchitz / Schwitzer). On polluted topics, Kahan's evidence implies that a pickup-worthy *and* effective release uses culturally-plural messengers, process-emphasis, and pre-emptive frame management. Outlets serving a particular cultural cohort (e.g., Fox, MSNBC, religious press) will pick up only releases whose frame aligns with their audience; supplying differentiated frames is therefore essential for cross-spectrum pickup.
