# Purdue OWL Press Release Writing Guidelines

## Content and Structure
- Press releases should contain new and useful information that readers will want or need to know
- Main idea and purpose should be at the beginning
- AP style typically used

## Length and Brevity
- Concise: aim for tight writing
- Each sentence must be meaningful
- Cut anything unnecessary

## Target Audience Considerations
- Make target audience interested in information
- Consider venue of release
- Account for secondary audience members
- But write specifically for primary target

## Distribution Considerations
- Be cautious with embargoes - media outlets often don't like holding releases
- Embargo only when there's clear need
- Otherwise risk: outlets may not use in news cycle

## Adapting for Different Media

### Format Variations
- Audio-only: avoid long strings of numbers
- Audio: avoid visual references
- Black-and-white print: avoid color-dependent descriptions
- Color media: can leverage visual descriptions
- Online: use multimedia, hyperlinks
- Broadcast: use shorter sentences, simpler vocabulary

## Style Standards
- AP Style guidelines apply
- Active voice preferred
- Concrete language
- Clear paragraph structure
- Factual tone

## Implicit Quality Rubric
- Information is new (not stale)
- Information is useful (provides value)
- Main point at beginning
- Each sentence meaningful (no filler)
- Format-appropriate for distribution medium
- Audience-targeted
- AP style throughout
- Tight, no padding
