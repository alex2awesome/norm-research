# AAAS Communication Toolkit — Goal-Audience-Message framework for science releases

The AAAS Communication Toolkit, developed for AAAS Communicating Science workshops, codifies a Goal-Audience-Message framework with explicit principles for storytelling, visuals, and message hierarchy. Each principle maps onto a press-release rubric criterion.

## AAAS Goal-Audience-Message framework as release rubric
1. **Goal definition first.** Before writing the release, define which goal it serves: share findings, build appreciation, inform a decision, change behavior, invite participation. Releases that conflate goals communicate less effectively.
2. **Audience definition second.** "Audience" is plural. Define which specific audience the release primarily serves (general public, policymakers, practitioner community, scientist peers, advocacy community). Releases written for "everyone" reach no one well.
3. **Message tailoring third.** Frame the big idea in ways most relevant to the named audience. A finding about a clinical trial framed for patients differs from the same finding framed for policymakers.

## AAAS message-development rubric (release-level)
4. **Three-message rule.** Identify the three core messages from the finding; do not try to communicate more than three in a single release.
5. **"Big point" first.** Lead with the bottom line — the most relevant outcome for the target audience — rather than methodological introduction.
6. **Inverted-pyramid hierarchy.** Most-important first, supporting detail later, methodology and limitations at the bottom; allow editors to cut from the bottom.

## AAAS storytelling rubric
7. **Examples over abstractions.** Verbal tools — examples, stories, analogies — illustrate key messages more effectively than technical statements.
8. **One named human.** Whenever possible, anchor the release in one named person whose story personalizes the finding (a researcher, a patient, an affected individual).
9. **Narrative arc.** Releases benefit from a recognizable shape: puzzle → investigation → finding; problem → approach → result; expectation → surprise → implication.

## AAAS visual rubric
10. **Visual-first thinking.** Determine the visual asset (image, diagram, infographic, video) before drafting text. Releases without supplied visuals lose pickup at all visual outlets.
11. **Data-image-narrative balance.** Find the appropriate balance for the audience; technical audiences accept more data, lay audiences need more narrative.
12. **High-resolution and rights-cleared.** Visuals must be at least 1500×1500 px, with usage rights cleared and credits supplied in caption text.
13. **Caption substantiveness.** Captions should make the visual interpretable without needing the surrounding text.

## AAAS engagement principles
14. **Authentic enthusiasm.** Scientists' genuine enthusiasm signals importance to readers; sterile institutional voice underperforms a quoted scientist's first-person curiosity.
15. **Acknowledge limits.** Honestly state what the study does not say; AAAS evidence supports that this builds rather than reduces credibility.
16. **Connection to daily life.** Frame findings in terms of audience daily experience (health, food, work, weather) where appropriate.

## Pickup-worthiness implication
AAAS-trained scientists working with PR offices to apply the Goal-Audience-Message framework consistently produce releases that pass intake at quality science-news outlets at higher rates. The framework's combination of clear goal, defined audience, three-message hierarchy, named human, narrative arc, and high-quality visual is now the *de facto* standard for university science releases.
