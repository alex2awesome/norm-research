# Social Media Press Release and AI-Era Digital Distribution

## Modern Digital Press Release Components

### Required for AI Discovery
- Schema markup (NewsArticle, PressRelease)
- Q&A format sections
- Direct answer formatting
- Entity-rich content (people, orgs, places)
- Citation-worthy data
- Structured data tags

### Required for Social Media Amplification
- Tweetable headline (under 280 chars)
- Pre-written social posts
- Square and vertical image versions
- Open Graph tags
- Twitter Card metadata
- Shareable quote graphics

## Multi-Channel Press Release Format

### Press Release Newsroom
- Long-form release
- Media contact
- Press kit
- All multimedia
- Boilerplate

### Twitter/X Thread
- 5-8 tweet thread
- Lead tweet with key stat
- Visual in lead
- Link to full release
- Tagged relevant accounts

### LinkedIn
- Long post format
- Professional framing
- Tagged executives
- Article reformat possible

### Facebook
- Headline + image
- Quote pull
- Link to full release

### Instagram
- Visual quote card
- Carousel for data points
- Stories with link

### TikTok / Reels
- 15-60 second video summary
- Founder explains in plain language
- Captions for accessibility

### YouTube
- Full video version
- Long-form for evergreen
- Embedded in newsroom

## AI Search Optimization (2025-2026)

### For ChatGPT, Perplexity, Google AI
- Cite sources clearly
- Include statistics with provenance
- Structured Q&A
- Entity-relationship clarity
- Authority signals (expert names, credentials)

### Emerging Standards
- Conversational tone (matches AI question style)
- Direct factual statements (extractable)
- Comparison claims with data
- "What/why/how/when" structured sections

## Implicit Modern Multi-Channel Rubric
1. Long-form release optimized for SEO
2. Schema markup correct

4. LinkedIn post prepared
5. Visual assets in multiple formats
