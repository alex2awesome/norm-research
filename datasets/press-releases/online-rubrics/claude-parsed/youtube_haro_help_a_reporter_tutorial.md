# YouTube HARO Tutorial: Pitching Reporters Through HARO

## What is HARO
- Help A Reporter Out (now Connectively)
- Reporters post queries; sources respond
- Three emails per day with 50+ queries each
- Best free path for early-stage PR

## The HARO Pitch Formula
- Subject line: match query exactly
- First line: identify yourself + credentials
- Then: direct answer to their question
- Then: 1-2 quotable sentences
- Then: contact info + photo link

## The 100-Word Rule
- Pitches over 100 words rarely get used
- Reporters scan for usable quotes
- Brevity = more likely to be quoted directly

## What Reporters Want From HARO
- Specific expertise that matches the query
- Quotable phrasing (no "in conclusion")
- Quick turnaround (often hours, not days)
- Verifiable credentials
- Headshot for byline if needed
- Willingness to be quoted by name

## What Kills HARO Pitches
- Generic answers that could come from anyone
- Pitching unrelated services
- Multiple paragraphs of throat-clearing
- Self-promotion before answering question
- Credentials that can't be verified
- Asking for "approval" before quote use

## Sample Pitch Structure
```
Subject: [Match exact query subject line]

Hi [Reporter Name],

I'm [Name], [Title] at [Company]. I have [credentials relevant to query].

[2-sentence direct answer to the question — quotable]

[1-2 specific examples or data points]

Available for follow-up: [phone] / [email]
Headshot: [link]
LinkedIn: [link]

[Signature]
```

## Quality Rubric for HARO Pitches
- Match query exactly
- Identify expertise immediately
- Provide quotable answer
- Stay under 100 words
- Include verifiable credentials
- Provide headshot link
- Available for fast follow-up
