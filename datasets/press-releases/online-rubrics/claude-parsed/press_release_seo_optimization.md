# Press Release SEO Optimization

## Key Strategies

### Keyword Integration
- Strategically place keywords in headline, subheadings, and body
- Balance: use naturally without overstuffing
- Keyword density 1-3% (no more)
- Include long-tail keyword variants

### Headline Optimization
- Catchy, clear, includes main keyword
- Under 70 characters for SERP visibility
- Front-load most important keywords (first 55 characters)
- Use power words

### Link Strategy
- Use 2-3 links per 500 words
- Don't include links in headlines
- Use descriptive anchor text (not "click here")
- Link to relevant landing pages
- Avoid excessive linking (search engines see as spam)

### Content Quality
- Press releases succeed when human, telling a real story, and useful
- Keywords should support the message, not dominate it
- Min 400-500 words for SEO purposes
- Original content - don't reuse text from other releases

### Multimedia
- Include images with alt text
- Video improves engagement metrics
- Embed metadata in images

### Distribution for SEO
- Use established newswires for backlinks
- Multiple syndication points
- Distribute through Reg FD-compliant channels for credibility

### Performance Tracking
- SEMrush / Ahrefs / Moz for backlinks and rankings
- Google Search Console for impressions and clicks
- Newswire analytics for distribution

## Modern Considerations
- Mobile-first formatting
- Structured data / schema markup
- Optimize for AI assistants (ChatGPT, Perplexity, Google AI)
- Voice-search-friendly phrasing

## Anti-Patterns
- Excessive keyword stuffing
- Buying backlinks
- Spammy distribution networks
- Identical text across multiple releases
- Hidden text or hidden links
