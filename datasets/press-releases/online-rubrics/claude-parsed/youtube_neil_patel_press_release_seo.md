# Neil Patel: Press Releases for SEO

## The SEO Reality of Press Releases
- Wire releases generate nofollow backlinks (limited SEO juice)
- Real SEO value comes from earned media coverage
- Press releases serve as keyword anchors for newsroom pages
- Should be optimized for both Google and Google News

## Keyword Strategy
- Primary keyword in headline (front-loaded)
- Same keyword in first paragraph
- Secondary keywords in subheaders (H2/H3)
- Brand name + keyword combination once
- Don't keyword-stuff — Google penalizes

## Headline SEO Rules
- 60 characters or less for full SERP display
- Front-load most important keyword
- Include brand name only if it's a recognized search term
- Use numbers when relevant
- Avoid clickbait — wire services reject

## Body SEO Best Practices
- 400-700 words optimal
- Use H2 subheaders for scannability
- Include 1-2 outbound links to credible sources
- Include 1-2 inbound links to your own pages
- Use anchor text that matches target keywords
- Include alt text for any embedded images

## Schema Markup Recommendations
- Use NewsArticle schema if hosting on own site
- Include datePublished, dateModified
- Add author and organization info
- Include headline and description
- Image schema for any embedded media

## Distribution for Maximum SEO
- Post on company newsroom FIRST
- Then wire distribution (3-7 days later for SEO ownership)
- Direct outreach to journalists for earned coverage
- Earned coverage = followed backlinks = real SEO

## Common SEO Mistakes
- Keyword stuffing
- Multiple links to homepage instead of relevant pages
- Generic anchor text ("click here")
- Wire-only with no own newsroom version
- No multimedia (Google News rewards images)
- Missing schema markup

## Quality Rubric for SEO
- Primary keyword front-loaded in headline
- 60-character headline limit
- 400-700 word body
- Subheaders for scannability
- 1-2 inbound + 1-2 outbound links
- Schema markup if self-hosted
- Newsroom version + wire + earned outreach
