# Catenaccio (2008) — Press release as hybrid informative/promotional genre

Catenaccio applies genre theory and pragmatic analysis to show that press releases occupy a hybrid position on the informative–promotional continuum. The communicative success of a release depends on managing the *tension* between these two functions in textual structure.

## Catenaccio's hybrid-genre diagnostic
A press release simultaneously serves:
- **Informative function:** delivers fact-payload to journalists who need ready-to-use news copy.
- **Promotional function:** advances the issuer's reputation, market position, or policy agenda.
The pickup-worthy release codifies the promotional purpose *within* informative form, so the journalist can copy without explicit promotional residue.

## Catenaccio's rubric criteria (textual features that codify the hybrid)
1. **Third-person reportive voice.** Release should read as a journalistic report on the issuer, not as the issuer's first-person speech. ("Acme Corporation announced today that..." — not "We are pleased to announce...")
2. **Reported-speech promotional payload.** Promotional claims belong in *attributed quotes* from named individuals ("'This is a transformative moment for the industry,' said CEO Y"). Bare promotional claims in the release voice are stripped by sub-editors.
3. **Information-density per sentence.** Each sentence should advance the news, not the brand. Catenaccio shows that releases with high "facts per sentence" survive transformation more intact.
4. **Boilerplate isolation.** Promotional company-description ("About Acme") belongs in a clearly demarcated boilerplate block at the bottom — never woven into the lead.
5. **Pragmatic appropriateness.** The register should match the journalist-receiver's expectations: factual, attributable, scannable, time-stamped.
6. **Avoidance of "self-praise" lexical bundles.** Catenaccio (and the lexical-bundle follow-up literature) shows press releases that overuse self-evaluative bundles ("leading", "best-in-class", "cutting-edge", "world-class") are stripped or rejected.
7. **Verifiability of promotional claims.** Promotional claims that survive sub-editing are those the journalist can verify (rankings, market-share data with source, awards with dates).
8. **News-value primacy.** The release should be evaluable as news independent of its promotional benefit; if every sentence is promotional, the release is rejected.
9. **Receiver-role multiplicity.** Catenaccio notes the release addresses both journalists *and* end readers (since releases are now public on the issuer's site). The hybrid release passes both audiences without slipping into one mode.
10. **Genre signposting.** The release should obey genre conventions (dateline, contact block, headline format, "—END—" marker) so the receiver immediately classifies it as a release rather than an advertorial.

## Pickup-worthiness implication
Catenaccio's analysis predicts that releases failing the informative/promotional balance — too promotional in the lead, too informative-only to advance the issuer's interest — are penalized by both pickup-rate (sub-editor rejection) and downstream return (issuer perception of low ROI). The optimal hybrid disguises the promotional in informative form so successfully that journalists copy without resistance.
