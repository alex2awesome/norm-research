# Marsh, Guth & Short — Strategic Writing rubric for press releases (40+ document types)

Marsh's *Strategic Writing* takes a *recipe-and-example* approach to 40+ PR/advertising document types, each with stepwise process guidance and a grading rubric. The release recipe and the surrounding strategic-writing framework jointly form a comprehensive release rubric.

## Marsh's nine-step strategic writing process (release-level reading)
1. **Strategy.** State the goal of the release, the target audience, and the message before drafting.
2. **Audience analysis.** Identify the receiving journalists' beats, deadlines, formats, and prior coverage.
3. **Channel selection.** Wire, direct email, embargo, social-first — choose based on audience analysis.
4. **Format selection.** Standard release? Announcement? Backgrounder? Media advisory? Statement?
5. **Drafting.** Apply genre conventions (lead, quote, inverted pyramid, boilerplate).
6. **Diversity & inclusion check.** Does language avoid stereotypes, exclusionary framing, single-perspective dominance?
7. **Ethics review.** Does the release pass PRSA Code compliance, accuracy, transparency?
8. **Legal review.** Does the release pass for libel, securities-disclosure (if material), copyright, trademark, FTC endorsement rules?
9. **Evaluation plan.** Define success metrics *before* publication.

## Marsh-specific rubric criteria
1. **Strategic-purpose statement.** A pickup-worthy release reflects a clearly articulated strategic purpose; releases lacking this read as scattered.
2. **Recipe adherence.** Marsh's recipe approach is explicit: certain ingredients (lead, quote, attribution, contact) must be present in fixed positions.
3. **Document-type fit.** A misclassified release (e.g., press release used where a media advisory was appropriate) underperforms; choose the genre appropriate to the news.
4. **Diversity & inclusion auditing.** Inclusive language, diverse spokespeople, accessible format. Quality outlets penalize releases that fail this dimension.
5. **Ethics-and-legal checklist.** Each release should be reviewed against ethical and legal flags before distribution.
6. **Evaluation accountability.** Marsh insists on planned evaluation. The release writer should know how success will be measured (clip count, sentiment, reach, downstream action).
7. **Multimedia integration.** Strategic writing in 2020s requires multimedia versions: social cards, video alt-version, podcast pitch.
8. **Cross-document consistency.** A release should be consistent with the issuer's other documents (annual report, social posts, executive bios) to avoid contradiction.

## Marsh's 40+ document-type ecology
A release is one of many tools. A pickup-worthy *campaign* uses the appropriate document for each task: media advisory for invitation, fact sheet for context, backgrounder for depth, op-ed for argument, briefing memo for decision-makers, social post for retail reach. A release that is asked to do all these jobs at once underperforms.

## Pickup-worthiness implication
Marsh's pedagogy predicts pickup is a function of *appropriate document selection plus correct execution within the chosen genre*. Releases written without the nine-step process — particularly without strategy, audience, and ethics reviews — accumulate failures (mismatched genre, inappropriate framing, missing diversity considerations) that reduce both pickup rate and downstream credibility.
