# Event Press Release Template and Standards

## Required Components for Event Releases

### Headline
- Concise, attention-grabbing
- Reflects event's main theme/news value
- Scanned in fraction of a second
- Include event name and key benefit

### Dateline
Standard format: "FOR IMMEDIATE RELEASE - [City, State] - [Date]"

### Opening Paragraph (5Ws + How)
Answer in first paragraph:
- WHO is hosting
- WHAT is happening
- WHEN it occurs (date and time)
- WHERE it takes place (venue, address)
- WHY it matters
- HOW to attend/register

### Body
- Bullet points for key details
- Short sections for scannability
- Speaker/agenda highlights
- Notable attendees
- Sponsor information
- Pricing and registration
- Press accreditation info

### Boilerplate
- Hosting organization description
- Reinforces credibility

## Pre-Event vs Post-Event Releases

### Pre-Event Release
- Send 4-6 weeks ahead for major events
- Send 2-3 weeks ahead for smaller events
- Reminder release 1 week before
- Include registration deadline

### Post-Event Release
- Send within 24-48 hours
- Highlight outcomes
- Include attendance numbers
- Quotes from notable speakers
- Photo/video assets
- Future event plans

## Best Practices
- Keep concise: 400-500 words
- One page ideal
- Strong newsworthy angle
- Speakers/celebrities highlighted
- Visual assets attached
- Press registration info
- Embargo if launching/announcing

## Implicit Quality Rubric for Event Releases
- All event logistics clear (date, time, venue, cost)
- Registration link/process clear
- Speaker bios/credentials provided
- Press accreditation process explained
- Visuals provided (logos, speaker photos)
- News angle beyond "we're having an event"
- Notable attendees/speakers featured
- Industry context provided
- Contact info for press kit
- Social media handles for amplification
