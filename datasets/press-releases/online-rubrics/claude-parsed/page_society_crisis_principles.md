# Page Society: Crisis Communications Principles

## The Page Principles in Crisis
- Tell the truth
- Prove it with action
- Listen to stakeholders
- Manage for tomorrow
- Conduct PR as if entire company depends on it
- Realize company's true character is expressed by people
- Remain calm, patient, and good-humored

## Applied to Crisis Press Releases

### Tell the Truth
- All known facts disclosed
- No selective omission
- Acknowledge what's not yet known
- Update when new facts emerge
- Correct misstatements promptly

### Prove It with Action
- Specific corrective steps
- Timeline for each action
- Named accountability owners
- Independent verification
- Public reporting of progress

### Listen to Stakeholders
- Multiple feedback channels
- Stakeholder concerns reflected in response
- Adjustments based on input
- Two-way communication
- Long-term engagement

### Manage for Tomorrow
- Long-term reputation focus
- Don't sacrifice future for today's optics
- Build durable trust
- Acknowledge systemic issues if present
- Policy/practice changes that prevent recurrence

## What Page Society Recommends

### Pre-Crisis
- Crisis playbook updated annually
- Spokesperson trained
- Stakeholder maps current
- Dark site ready
- Relationships with media established

### During Crisis
- Acknowledge within 2 hours
- Initial release within 24 hours
- Substantive update within 72 hours
- Resolution reporting in weeks
- Long-term commitments honored

### Post-Crisis
- Audit lessons learned
- Update playbook
- Restore stakeholder trust
- Track sentiment over time
- Make systemic changes

## Quality Rubric (Page Society)
- Truthful disclosure
- Concrete actions named
- Stakeholder voices reflected
- Long-term reputation focus
- Pre-crisis playbook ready
- Update commitments honored
- Lessons learned applied
