# Bowen, Davis & Matsumoto (2002) — Conference calls as a release-ecosystem complement

Empirical study showing earnings conference calls increase analyst forecast accuracy and reduce dispersion. The press release does not stand alone; its effective reach is amplified (or undercut) by the surrounding voluntary-disclosure system.

## Headline empirical findings
1. **Conference calls increase analysts' forecast accuracy** — implying the call adds information beyond the press release.
2. **Conference calls reduce forecast dispersion** — analyst convergence increases.
3. **Effects are larger for firms with higher analyst following** — a size/coverage interaction.

## Bowen-Davis-Matsumoto rubric criteria for press release ecosystems
1. **Press-release / conference-call alignment.** The release should cover all material headline items; the call expands narrative and Q&A. If the call introduces material new information not in the release, the release was incomplete.
2. **Pre-call release timing.** Release distribution must precede the call by enough time that participants can read it (typically 30+ minutes); release-after-call is a Reg FD violation if any material content varies.
3. **Q&A-anticipation hooks.** Include in the release the data and context that analysts will ask about anyway. This signals preparation and converts well into call time.
4. **Forward-looking guidance placement.** Quantitative guidance should appear in the press release proper (with safe-harbor language), not only in the call. Per Bowen et al., guidance affects analyst forecasts measurably.
5. **Reconciliation table.** Pro-forma to GAAP reconciliations belong in the release, not in the call deck — analysts demand the audit trail.
6. **Call-script consistency.** Prepared remarks should not contradict the release; deviations are flagged by analysts as either error or strategic shading.
7. **Q&A transcript availability.** Same-day transcript posting expands the release's downstream reach to analysts and journalists who could not join live.
8. **Multiple-channel coverage.** Releases should anticipate that some analysts read only the release (small-cap coverage), some attend only the call (large-cap), some read only the transcript. Each channel should carry the core message.

## Pickup-worthiness implication
Bowen, Davis & Matsumoto's finding that calls raise analyst accuracy implies that releases on their own *under-deliver* if not paired with a call. For pickup-worthy financial releases, the appropriate question is whether the call/release pair *together* maximize analyst (and downstream journalist) forecast accuracy, not whether the release alone gets reproduced. Releases without an accompanying call signal lower transparency to sophisticated coverage and get demoted accordingly.
