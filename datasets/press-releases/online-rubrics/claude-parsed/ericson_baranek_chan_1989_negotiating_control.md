# Ericson, Baranek & Chan (1989) — Negotiating Control: pickup as negotiated access

Ericson, Baranek & Chan's ethnography in Toronto courts, police, government and commercial sources develops the *negotiated control* frame: news access is the outcome of an ongoing negotiation between sources who control information and journalists who control publication. The press release is one move in this negotiation.

## Negotiated-control diagnostic claims
1. **Sources control information; journalists control publication.** Each side has resources the other needs.
2. **Access is negotiated continuously**, not granted once. Each release is an episode in a longer dance.
3. **Sources differ on a control–access trade-off**: more control over the message means less media access; more access means less control.
4. **Different sources favor different control-access settlements**: police and courts seek high control; advocacy groups accept lower control for higher access.

## Ericson-Baranek-Chan rubric criteria
1. **Control-access trade-off discipline.** A release that demands too much control (right to review, no-quote conditions, embargoed-only release) will be picked up less. A release that surrenders all control (open data dump) will be picked up but framed by others. Choose the trade-off appropriate to the issuer's strategic posture.
2. **Negotiation continuity.** Each release is part of an ongoing relationship. Burn the relationship by misleading the journalist on this release, lose pickup on the next twenty.
3. **Information-asymmetry leverage.** Sources can supply context only they have; releases that leverage this asymmetric advantage (insider expertise, on-the-ground witnesses) earn deeper pickup.
4. **Beat-source access bargain.** Sources who reliably supply the beat's news in exchange for cooperative coverage maintain pickup; sources who provide only press releases without follow-up access lose ground.
5. **Risk-of-attribution awareness.** Sources should consider what attribution risks the journalist faces; on-record release with named spokesperson reduces journalist risk and increases pickup.
6. **Defendability under scrutiny.** Each release should withstand a journalist's editor asking "is this defensible?" — releases that pass this defendability check are run; releases that don't trigger callbacks or rejection.
7. **Two-tier release architecture.** Some releases are designed for control (carefully crafted, embargoed); others for access (background packets, expert availability). A sophisticated release program operates both tiers.
8. **Source-journalist bargain renewal.** When the issuer's access bargain has degraded (after a missed embargo, an inaccurate release), releases should explicitly acknowledge this and offer a corrective action to rebuild trust.
9. **Investigative-cooperation supply.** Sources who supply investigative material (FOI documents, internal reviews) build access credit even when individual releases fail.
10. **Police/court/regulator-style precedent.** Releases from heavily-routinized sources (police, courts, regulators) get auto-pickup because the negotiation is institutionalized; a release from a non-routinized source must rebuild the negotiation each time.

## Pickup-worthiness implication
Ericson, Baranek & Chan predict that pickup-worthiness is dominantly a function of the *quality of the source-journalist negotiation* the release sits within, not just text quality. Releases optimized for short-term control at the expense of long-term access perform badly; releases that respect the negotiation, supply control-and-access in the appropriate trade-off, and renew the bargain when broken sustain pickup over time.
