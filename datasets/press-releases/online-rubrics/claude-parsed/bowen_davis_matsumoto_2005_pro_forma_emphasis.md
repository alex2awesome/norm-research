# Bowen, Davis & Matsumoto (2005) — Strategic emphasis on pro-forma vs. GAAP

Studied (i) determinants of metric emphasis in earnings releases, (ii) whether emphasis shifted post-SEC intervention, and (iii) whether market response is influenced by which metric receives emphasis.

## Headline empirical findings
1. **Firms emphasize metrics that portray more favorable performance** — emphasis is strategic, not random.
2. **Firms with more media exposure place greater emphasis on pro-forma earnings** than on GAAP — sophisticated PR offices game the press release for media-friendly framing.
3. **Markets respond to the emphasized metric** — investors treat the emphasized number as more important.
4. **SEC intervention shifted emphasis somewhat** but did not eliminate strategic framing.

## Bowen-Davis-Matsumoto rubric criteria for earnings releases
1. **GAAP-first ordering.** Post-Reg-G, releases must reconcile any non-GAAP metric with the GAAP equivalent and place the GAAP figure in equal or greater prominence. Releases violating this draw SEC comment letters.
2. **Headline-metric defensibility.** Whatever earnings metric is in the headline, the release must defend its use over GAAP in the explanatory paragraph.
3. **Reconciliation table inclusion.** A clearly labeled reconciliation between any non-GAAP metric and the closest GAAP equivalent should appear in the release body.
4. **Comparable-period basis.** When emphasizing a metric, use the *same* metric in prior-period comparisons; switching basis between periods is flagged by analysts.
5. **Adjustment definition consistency.** Any "adjusted" metric should use the same definition every quarter; redefining mid-year is flagged.
6. **Emphasis-vs-substance audit.** If the release emphasizes a metric that diverges sharply from GAAP (large one-time-charge add-backs), the release should explain why the adjustment is conceptually appropriate.
7. **Order-of-information consistency.** The order in which results appear (revenue → operating income → net income → EPS → adjusted EPS) should follow industry convention; reordering to lead with the most flattering line is detectable and gets flagged.
8. **Media-exposure-bias check.** High-media-exposure firms face greater scrutiny; releases should be drafted assuming sophisticated reading rather than only retail-investor reception.

## Pickup-worthiness implication
At sophisticated outlets (FT, WSJ, Bloomberg, Reuters), emphasis on a flattering non-GAAP metric over GAAP triggers analytical scrutiny rather than uncritical reproduction. A pickup-worthy *and* defensible earnings release uses non-GAAP metrics where they have clear analytical justification, reconciles to GAAP visibly, maintains period-over-period definition consistency, and trusts that sophisticated readers reward transparency over flattering framing.
