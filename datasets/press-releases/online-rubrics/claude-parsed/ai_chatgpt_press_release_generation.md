# AI-Era Press Release Generation Standards

## Effective Prompt Structure for AI-Generated Releases

### Required Inputs
- Specific news event
- Target audience
- Tone (journalistic, formal, conversational)
- Length target (300-500 words)
- Key facts (5Ws + H)
- Quotes desired
- Industry context

### Best Prompt Practices
- Be specific, not generic
- Provide real facts, not placeholders
- Set tone explicitly
- Reference style guide (AP)
- Iterate (don't expect first draft to be final)

## AI as Drafting Tool, Not Final Author

### Strong Use Cases
- First draft generation
- Multiple version drafts
- Translation
- Format conversion (long to short)
- Headline brainstorming
- Subhead generation

### Weak Use Cases
- Original quotes (must be from real people)
- Verifiable facts (AI can hallucinate)
- Sensitive announcements
- Crisis communications
- Material/financial disclosures

## AI Search Optimization for Releases

### To be discoverable in ChatGPT, Perplexity, Google AI:
- Cite all sources clearly
- Include statistics with provenance
- Use structured Q&A sections
- Make entity relationships clear
- Provide authority signals
- Conversational tone (matches AI question style)
- Direct factual statements (extractable)

## Quality Issues with AI-Generated Releases

### Common Problems
- Generic tone
- Buzzword-laden
- Hallucinated facts
- Same template structure
- Missing authentic voice
- Lacks specific detail
- Over-promotional language

### Required Human Review
- Fact verification
- Quote authenticity
- Source verification
- Brand voice check
- Tone calibration
- Originality check

## Implicit Quality Rubric for AI-Generated/Assisted Releases

A press release that effectively uses AI:
1. Human-edited after AI draft
2. All facts verified (no hallucination)
3. Quotes from real interviews
4. Brand voice consistent
5. Specific (not generic) details
6. Original (not template feel)
7. AI-search optimized (schema, structure)
8. Human review for sensitive content
9. Ethics: AI assistance disclosed where required
10. Multiple iterations (not first draft)

## Modern AI-Era Considerations
- Press releases now compete in AI summaries (not just SERPs)
- AI may extract quotes verbatim - make them quotable
- Structure for both human and AI parsing
- Schema markup increasingly important
- "Cite-worthy" content gets surfaced more
