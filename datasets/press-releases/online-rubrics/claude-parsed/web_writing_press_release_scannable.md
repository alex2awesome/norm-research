# Web Writing Standards for Scannable Press Releases

## Foundation (Nielsen Norman Group)
Web text should be:
- Short
- Scannable
- Structured as linked, topical pages

## Key Guidelines

### Length
- Web: 50% of hardcopy text
- Press release: 400-500 words ideal
- Less is more for digital readers

### Scannability
- Avoid long continuous blocks of text
- Use headings
- Use bullet points
- Use bolded keywords
- White space matters

### Hypertext
- Link to source documents
- Link to related releases
- Link to research papers (DOI)
- Link to images/multimedia
- Link to bio pages

## Paragraph Structure

### Standard
- 2-4 sentences per paragraph
- 2-3 sentence ideal
- Single idea per paragraph
- Front-load with topic sentence

### Why
- Users scan, don't read
- Pick keywords, sentences, paragraphs of interest
- Skip parts they care less about
- Web reading 25% slower than print

## Web-Specific Press Release Elements

### Required for Web
- Headings/subheadings
- Bulleted lists where applicable
- Bold for key terms
- Hyperlinks (descriptive, not "click here")
- Alt text on images
- Mobile responsive layout

### Multimedia Requirements
- Compressed images (fast load)
- Web-friendly formats (JPG, WebP, MP4)
- Lazy loading
- Responsive images (multiple sizes)
- Captions

### Engagement Elements
- Embedded video
- Interactive data
- Social share buttons
- Related stories
- Newsletter signup

## Implicit Web-Optimized Rubric

A press release is web-optimized if:
1. Under 500 words
2. 2-4 sentence paragraphs
3. Subheadings for sections
4. Bullet points where applicable
5. Bold key terms
6. Descriptive hyperlinks
7. Alt text on all images
8. Mobile-responsive layout
9. Page loads under 3 seconds
10. Schema markup present
11. Open Graph tags
12. Twitter Card tags
13. Social sharing widgets
14. Related content links
15. Accessible (Section 508 / WCAG)

## Cognitive Load Considerations
- Read aloud test: clear and easy?
- Skim test: can extract main points by scanning?
- F-pattern reading: top-left and headlines optimized?
- Inverted pyramid: most important first?
