# Prowly Blog: Press Release Template With Annotations

## Annotated Template Structure

### Header Section
```
FOR IMMEDIATE RELEASE / EMBARGOED UNTIL [date/time]
[CITY, State / Country] — [Date]
[HEADLINE: 8-12 words, news-first]
[Subheadline: optional, expands on news]
```
*Why: Standard format reporters scan for*

### Lede Paragraph
```
[Company/Person] today announced [news] that [why it matters].
[Specific detail: number, date, named entity].
```
*Why: 5 W's compressed into 50 words*

### Body Paragraphs (2-4 max)
- Para 2: Context — why this matters in the broader market
- Para 3: Quote from C-level spokesperson (substantive, not generic)
- Para 4: Specifics — methodology, timeline, partners
- Para 5 (optional): Customer/partner quote

### Boilerplate
```
About [Company]
[75-word company description]
[Website link]
```
*Why: Background for unfamiliar readers; under 75 words*

### Contact Info
```
Media Contact:
[Name]
[Title]
[Phone]
[Email]
```
*Why: One named contact, phone REQUIRED, email second*

### End Marker
```
###
```
*Why: Industry standard "end of release" marker*

## Annotated Common Mistakes

### Mistake: "We are excited to announce"
*Why bad: Filler that journalists skip; replace with the news directly*

### Mistake: Headline like "Acme Corp Unveils Revolutionary Solution"
*Why bad: No news in headline; rewrite as "Acme Corp Cuts Wait Times 50% With New Software"*

### Mistake: Quote that says nothing
*Why bad: Wastes valuable real estate; rewrite to add information*

### Mistake: Boilerplate that takes 200 words
*Why bad: Too long; reporters won't use, makes release feel padded*

## Quality Rubric (Prowly)
- Standard header format
- 50-word lede with 5 W's
- 2-4 body paragraphs max
- Substantive quote from named spokesperson
- 75-word boilerplate max
- Named media contact with phone
- Industry-standard end marker
