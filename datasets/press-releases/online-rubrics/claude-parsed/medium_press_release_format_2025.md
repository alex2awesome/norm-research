# Medium: The Modern Press Release Format for 2025

## What's Different in 2025
- AI summarization rules — write for LLM extraction
- Mobile-first format mandatory
- Multimedia hub model preferred over text-only
- Social media kit integrated
- Schema markup expected
- Translation often needed

## The 2025 Press Release Anatomy

### Header (Mobile-Friendly)
- Logo
- "FOR IMMEDIATE RELEASE" or embargo
- Date and city
- Headline (60 chars for mobile)
- Subhead (optional, expanded mobile view)

### Lede (50 Words Max)
- 5 W's compressed
- Mobile-readable in one swipe
- Tweetable one-line summary at top

### Body (300-500 Words)
- Inverted pyramid
- One idea per paragraph
- Mobile-friendly subheaders
- Embedded multimedia at relevant points
- Pull-quote on first scroll

### Quotes (Substantive)
- 25-35 words
- Pull-quote format for visual emphasis
- Attribution with title and credentials
- Available as standalone social asset

### Multimedia Hub
- Hero image (1200x630)
- Video (under 60 sec for mobile)
- Infographic with social dimensions
- Headshot library
- B-roll for broadcast
- All downloadable without registration

### Social Media Kit
- Tweet-length quotes
- LinkedIn post drafts
- Instagram-ready visuals
- TikTok-ready video clips
- Hashtag recommendations

### Schema.org Markup
- NewsArticle type
- Headline, datePublished, dateModified
- Author and Organization
- Image references
- Multilingual versions if applicable

### Boilerplate (Concise)
- 50-75 words
- Founded date, headquarters
- Mission in one sentence
- Key metrics
- Website URL

### Contact (Mobile-Friendly)
- Named contact
- Direct phone (clickable on mobile)
- Direct email (clickable)
- Calendar booking link
- Time zone

### End Marker
- "###" still standard

## Distribution for 2025
- Mobile-optimized HTML version
- AI-readable structured data
- Multi-language versions
- Social-native formats
- Wire for SEO floor
- Direct outreach for pickup

## Quality Rubric for Modern Releases
- Mobile-first formatting
- 50-word lede
- 300-500 word body
- Multimedia hub
- Social media kit
- Schema markup
- Multilingual where appropriate
- AI-summarization-friendly structure
