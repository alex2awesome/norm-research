# NASEM (2017) — Five crosscutting themes applied to press releases

NASEM's consensus report synthesizes evidence on science communication effectiveness. Its five crosscutting themes (plus the embedded systems approach) constitute a release-level rubric grounded in the research agenda's evidence base.

## NASEM's five themes (release rubric)
1. **Align strategy with goals.** The release must declare (internally) which goal it serves: sharing findings, building appreciation, increasing knowledge of an issue, influencing opinion or behavior, or eliciting public input. Releases that conflate goals communicate poorly.
2. **Tailor messages to specific audiences.** Different versions or framings are needed for general public, scientists, media, advocacy groups, corporations, health professionals, government agencies, science enthusiasts, policy makers, political commentators, and individual activists. NASEM explicitly rejects one-size-fits-all releases.
3. **Deal honestly with complexity and uncertainty.** Releases should not paper over scientific uncertainty; they should communicate it in ways the audience can use ("an early-stage finding," "subject to replication," "consistent with but not yet proving X").
4. **Go beyond the deficit model.** The deficit model assumes the audience needs facts and will then agree. NASEM's evidence rejects this: communication must engage values, identities, and contexts. Releases should not assume that "if we explain the science, opposition will end."
5. **Frame issues so audiences are receptive.** Frame choice (per Hallahan, Kahan) should reflect audience values rather than the scientist's internal frame.

## Systems-approach criteria
6. **Recognize complexity of communication processes.** A release is one node in a system: scientist → PR office → release → wire → reporter → editor → reader → social media → repeat. Pickup-worthy releases anticipate the full chain.
7. **Evaluation built in.** NASEM recommends communications efforts include planned evaluation. Each release should specify success criteria *before* publication (clip count, sentiment, downstream policy outcomes, public-survey shifts).

## Domain-specific NASEM rubric criteria for contentious-science releases
8. **Cultural-cognition awareness.** Releases on topics with known cultural-cognition divides (climate, vaccines, GMO, AI) should test the frame against multiple cultural worldviews.
9. **Trust-building over persuasion.** NASEM evidence: trust accrues over repeated honest communication. A single release should not aim to convert; it should sustain trust.
10. **Information ecosystem awareness.** The release lives in a contested information ecosystem. NASEM advises content that is robust to mis-quotation and stands up under partial reproduction.
11. **Stakeholder participation.** For contentious topics, NASEM endorses including affected community voices in the release rather than only scientist voices.

## Pickup-worthiness implication
NASEM's framework predicts that the highest-quality science press releases — those most reliably picked up by quality outlets and least likely to generate corrective coverage — adopt all five themes plus the systems perspective. Releases that violate the deficit-model warning (i.e., over-explain expecting behavior change) tend to backfire on contentious topics.
