# USPTO Patent Public Search (PPubs) and PE2E

## Overview

Patent Public Search (PPUBS) is based on the advanced **Patents End-to-End (PE2E)** search tool USPTO examiners use to identify prior art. It is a free, cloud-based platform combining four legacy tools:
- PubEAST (Public-Examiner's Automated Search Tool)
- PubWEST (Public-Web-based Examiner's Search Tool)
- PatFT (Patent Full-Text and Image Database)
- AppFT (Patent Application Full-Text and Image Database)

## Key Features and Benefits

- Free online search tool for all U.S. published patent applications and patent grants
- Remote searching available to all users
- Multiple layouts with multiple tools
- Multi-color highlighting
- Document tagging into multiple groups
- Add notes to images with tags
- Save searches and tag patents

## Search Capabilities

### Field-Specific Searching
- Inventor name
- Assignee name
- Application number / publication number
- Classification (CPC, IPC, USPC)
- Claim text
- Specification text
- Date ranges
- Priority dates

### Boolean Operators
- AND, OR, NOT
- Phrase searching with quotes
- Wildcard characters (* for stem, ? for single character)
- Proximity operators (NEAR, ADJ)

### Classification Search
- CPC (Cooperative Patent Classification)
- IPC (International Patent Classification)
- USPC (legacy U.S. classification, pre-2013)
- F-terms (Japan)

## Search Strategy Best Practices

### 1. Define Search Concepts
- Identify main technical concepts
- Develop synonyms for each concept
- Consider technical and lay terms

### 2. Iterative Approach
- Start broad with classifications
- Narrow with keywords
- Refine based on initial results

### 3. Use Multiple Strategies
- Classification searching
- Keyword searching
- Citation analysis (forward and backward)
- Inventor and assignee searches
- Co-classification combinations

### 4. Document Your Search
- Save search strategies
- Note databases searched
- Date searches
- Track relevant results

## Examiner Workflow Insight

USPTO examiners use PE2E to:
- Search prior art using classification + keyword combinations
- Build search histories that become part of the file wrapper
- Identify references for office action rejections
- Document search efforts for quality review

## Drafting Insights from Search Tool Knowledge

Understanding examiner search patterns helps drafters:
- Use technical terminology examiners are likely to find
- Include synonyms in claim language
- Consider classification placement when drafting
- Anticipate which references examiners will likely cite
