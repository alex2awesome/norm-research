# Continuation, Divisional, and Continuation-in-Part Applications

## Key Definitions

Divisionals, continuations, and continuation-in-parts (CIPs) are continuing patent applications that stem from an earlier filing.

### Divisional Applications
A divisional claims a distinct invention disclosed but not claimed in the parent, filed in response to a restriction requirement.
- Contains the cancelled claims (or equivalent)
- Claims priority to the original application's filing date
- Examined separately
- Issues as a separate patent
- Protected by 35 USC 121 safe harbor (no double patenting)

### Continuation Applications
A continuation application is a re-filing of an existing patent application:
- Receives a new serial number
- Same specification as parent (no new matter)
- Claims same subject matter as the earlier parent
- Claims priority to the parent's filing date
- Allows new claims targeting different aspects

### Continuation-in-Part (CIP) Applications
A CIP includes new matter (additional disclosure) along with the parent's disclosure:
- New matter does not get earlier filing date
- Original matter retains priority date
- Each claim's priority date depends on what disclosure supports it
- Useful for incremental improvements

## Strategic Use

| Application Type | When to Use |
|------------------|-------------|
| Divisional | After restriction requirement; pursue non-elected inventions |
| Continuation | Capture new claim scope; respond to competitor activities; broader claims |
| CIP | Incorporate post-filing improvements |

## Critical Timing Requirements

All three types must be filed while the earlier patent application is still pending. Once a patent application is abandoned or a patent issues and the issue fee is paid, the window for filing most continuing applications closes.

## Portfolio Management

A patent family tree should be designed when the parent is drafted to:
- Ensure the specification supports divisional and continuation claims
- Cover competitor design-arounds
- Coordinate claim scope across family members
- Prevent over-breadth that invites invalidity challenges
- Avoid under-breadth that leaves commercial embodiments unprotected

## Strategic Continuation Pendency

Best practice: Maintain at least one continuation in every family pending until the patent term expires. This allows:
- Adapting claims to new infringers
- Capturing claim scope discovered during litigation
- Responding to design-arounds

## Restrictions and Limitations

- USPTO occasionally tries to limit continuation practice
- Continuations cannot extend term beyond parent + RCE + various adjustments
- Patent term adjustment (PTA) may differ between parent and continuation
- Double-patenting requires terminal disclaimer if claims not patentably distinct

## Best Practices

- File continuation before issue fee is paid in parent
- Disclose all known prior art in continuations (duty of candor continues)
- Consider RCE vs. continuation strategically
- Track relationship between parent and continuations carefully
