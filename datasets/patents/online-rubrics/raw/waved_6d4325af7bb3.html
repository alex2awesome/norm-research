Search Result List (Trial Decision Search (Opposition))

A search result list of the oppositions that are searched for by using the Trial Decision Search can be viewed.

"Opposition (XXXX)" tab

XXXX shows the hit count. (Example: When the hit count is 60, "60" is displayed in the parentheses.)

Selecting the "Opposition (XXXX)" tab opens the Search Result List screen for oppositions.

If the hit count is 0 or more than 3,000, an error occurs and the Search Result List is not displayed.

Search list options

The results of the Search Result List can be narrowed down by selected items.

By four law categories

The search results are displayed as hit counts for each law category (Patents, Utility models, Designs, or Trademarks). Each hit count is displayed as a link.

The number in the parentheses for each item name shows the hit count. (Example: When the hit count is 60, "60" is displayed in the parentheses.)

Select a link for an item to narrow down the results of the Search Result List by the selected item.

When a link for an item is selected, the hit count for the item is displayed without a link.

  • All

  • Patents (X)

  • Utility models (X)

  • Designs (X)

  • Trademarks (X)

By appeal or trial decision year

The search results are displayed as hit counts by appeal or trial decision year. Each hit count is displayed as a link.

Select a link for an item to narrow down the results of the Search Result List by the selected item.

When a link for an item is selected, the hit count for the item is displayed without a link.

If there are some dates such as partially fixed dates, the target narrowing-down will be each of them.

By conclusion of trial decision

The search results are displayed as hit counts for each conclusion of trial decision. For the top three items, the hit count of each item is displayed as a link.

Select a link for an item to narrow down the results of the Search Result List by the selected item.

When a link for an item is selected, the hit count for the item is displayed without a link.

For conclusion of trial decision codes that are displayed, refer to Conclusion of Trial Decision Code/Conclusion of Judgment Code List.

Display format of document display page

Select either of the following display formats of a document that is displayed in the Document Display screen.

  • Text Display

    The Document Display screen displays a document in text format.

  • PDF Display

    The Document Display screen displays a document in PDF format.

"Multiple PDF Download" button

Clicking the "Multiple PDF Download" button when box on the "No." column is marked opens an authentication screen.

Follow the on-screen instructions to complete authentication.

When authentication is successful, you can download multiple Japanese documents at one time.

*You can select 20 documents at most at once.

*PDF file will be downloaded in ZIP format as well if you select just one file.

*Trial decision bulletins are unavailable for this download.

*Publication displayed in "Opposition number" on the Search Result List will be downloaded.

"Print List" button

Clicking the "Print List" button opens the Print List screen. In the Print List screen, a search result list can be printed.

"CSV Output" button

Clicking the "CSV Output" button opens the Authentication for CSV Output screen.

When application for the use of CSV output is acknowledged, a search result list can be output in CSV format. However, outputting in CSV format is possible only when there are 500 or fewer search results.

If there are 501 or more search results, revise the search criteria so that only 500 or fewer results are returned.

Application for the use of CSV output can be submitted in the Authentication for CSV Output screen. For more information, refer to the Operation Manual.

(Search result list)
No.

The item number of each search result item is displayed as a series of numbers starting from 1.

Four law categories

One of the four law categories is displayed.

Kind

The type of the trial/appeal is displayed.

Opposition number

The opposition number is displayed.

If a trial decision is partially fixed, the decision date of the partially-fixed trial decision is displayed under the opposition number.

The opposition number and the decision date of the partially-fixed trial decision are displayed as links when relevant documents are available.

Additionally, when the bulletin for the trial decision is available, the "Bulletin" icon is displayed on the right of the opposition number.

Clicking a link opens the Document Display screen.

Appeal or trial decision date

The appeal or trial decision date is displayed. If there are some dates such as partially fixed dates, all of the appeal or trial decision dates will be shown.

*If there are some dates, it will be sorted with the newest date.

Classification/Class

The classification or class is displayed.

Name/Trademark (for search)

The name or trademark for search is displayed.

The trademark for search is a reading that is supplied so that a figure trademark can be searched for.

For some trademarks, the data for search is not stored. In this case, a hyphen (-) is displayed.

Opponent

The name of the opponent is displayed.

When there is more than one opponent, only the name of one person is displayed and the names of the other persons are omitted and displayed as "Other".

Right holder

The name of the right holder is displayed.

When there is more than one right holder, only the name of the head person is displayed and the names of the other persons are omitted and displayed as "Other".

Conclusion of trial decision

The conclusion of the trial decision is displayed.

Options

The following button is displayed.

"human translation" button

This button is displayed when the PDF of the human translation version of a document is available.

Click the "human translation" button to display the PDF of the human-translated document.

"Details" button

Clicking the "Details" button opens the Inquiry of history information screen.

"Jump to Top of List" button

Clicking the "Jump to Top of List" button moves to the top of the search result list.
