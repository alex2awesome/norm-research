# K.M. Weiland — Novel-Writing Checklist (Helping Writers Become Authors)

Five foundational elements every novel needs, from a craft blog with extensive structure-focused teaching.

## 1. Structure

- **Three Acts**: Setup, Conflict, Resolution
- **Three Major Plot Points**: First Plot Point (~25%), Midpoint (~50%), Third Plot Point (~75%)
- **Two Pinch Points**: First Pinch Point (~37%), Second Pinch Point (~62%)
- A strong **Hook** in the opening
- A strong **Climax** and **Resolution**

## 2. Character Arc

The protagonist needs:
- **A Lie They Believe** — the false worldview rooted in past wound
- **A Truth** — the new worldview the story will lead them to
- **A Want** — externally driven, sourced from the Lie
- **A Need** — internally true, resolved by accepting the Truth
- **A Ghost** — the past wound that produced the Lie
- **A Characteristic Moment** — opening scene that crystallizes who they are at the start

## 3. Theme

- Theme **emanates from character actions**, not stated assertions
- Connects directly to plot — embedded, not appended
- Argues a **complex moral position**, not simplistic good vs evil
- Echoed (but not repeated) by subplots and supporting characters

## 4. Setting

- Setting must **matter to the plot** as catalyst, not backdrop
- Possesses historical backstory that enriches credibility
- Influences supporting cast organically
- Creates atmosphere that reinforces theme

## 5. Point of View

- Choose narrator(s) strategically (typically protagonist)
- Decide narrative **distance** (deep POV vs. distant)
- Decide **tense** (past vs. present)
- Maintain **voice consistency**

## Three-Act Structure Beats (Weiland's Schema)

| Beat | Position |
|------|----------|
| Hook | 1% |
| Inciting Event | 12% |
| First Plot Point | 25% |
| First Pinch Point | 37% |
| Midpoint / Second Plot Point | 50% |
| Second Pinch Point | 62% |
| Third Plot Point | 75% |
| Climax | 88% |
| Climactic Moment | 98% |
| Resolution | 99% |

## Evaluative Use

A draft can be checked against each beat's position; missing beats or wrong placement diagnose pacing problems.
