# Roland Barthes — The Five Codes of Narrative (S/Z, 1970)

Structuralist framework for analyzing narrative texts. Barthes used these to read Balzac's "Sarrasine" line by line. They form a five-axis rubric for understanding what any narrative passage is doing.

## The Five Codes

### 1. Hermeneutic Code (HER)
The "voice of truth" — the mysteries, enigmas, and questions a narrative poses and gradually answers. Includes:
- Posing the question (formulation)
- Suspending the answer (delay, snare, partial answer, jamming)
- Eventually disclosing (resolution)

A narrative's suspense is built on the hermeneutic code.

### 2. Proairetic Code (ACT)
The "voice of empirics" — the actions and behavioral sequences. Names of actions ("decision," "departure," "meeting," "battle") that the reader recognizes as conventional units. Drives plot forward through chains of action.

The proairetic code is what gives a narrative its sense of "what happens next."

### 3. Semantic Code (SEM)
The "voice of the person" — the connotations attached to characters, objects, settings (a character's name evokes wealth; a setting's color evokes mood). The flicker of meanings around any narrative element.

Builds character and atmosphere through accumulated connotation.

### 4. Symbolic Code (SYM)
The "voice of symbol" — the larger thematic oppositions and binaries that organize the work (life/death, light/dark, masculine/feminine, inside/outside). Symbols cluster into structuring antitheses.

Provides the deep structure of meaning — what the work is "about" at the symbolic level.

### 5. Cultural / Referential Code (REF)
The "voice of science" — references to bodies of knowledge outside the text (medicine, history, geography, gossip, common sense). The text relies on the reader's cultural literacy.

Anchors the narrative in shared cultural knowledge; shifts as cultures shift.

## How They Interact

Barthes argued that any narrative passage simultaneously activates **multiple codes**. A single sentence may pose a hermeneutic question, name an action (proairetic), connote a character trait (semantic), invoke a binary (symbolic), and rely on cultural reference. The art of fiction is the layered orchestration of these codes.

### Functional Pairings
- **HER + ACT** → internal chronology, plot drive
- **SEM + SYM + REF** → connotative depth, thematic resonance

## Plurality of the Text

Barthes's deeper claim: a "writerly" (scriptible) text foregrounds the plurality of these codes — the reader actively constructs meaning. A "readerly" (lisible) text suppresses plurality — meaning is delivered.

A readerly text is more accessible; a writerly text is more profound.

## Evaluative Criteria

A narrative passage / work can be analyzed on:
- Which codes it activates
- How rich the activation is in each code
- Whether the codes harmonize or contend
- Whether the text is readerly (single-coded, predigested) or writerly (multi-coded, productive)
- Whether the hermeneutic code maintains tension or releases it prematurely
- Whether symbolic oppositions are productive or schematic

## Application as Rubric

A short story can be coded line-by-line for HER/ACT/SEM/SYM/REF activation. Density and balance reveal craft level. A story dominated only by the proairetic (action) reads as plot-driven but thin; one rich in all five reads as literary.
