# Character Arcs — Types & Craft Criteria

## The Four Basic Arcs (K.M. Weiland framework)
1. **Positive Change Arc** — Character starts in a Lie, faces ordeal, embraces a Truth, transforms.
2. **Negative Change Arc** — Character spirals into worse belief/morality (tragic / corruption arc).
3. **Flat / Static Positive** — Character holds the Truth from the start; *changes the world* around them.
4. **Flat / Static Negative** — Character is stuck in a Lie they never escape.

## Sub-types of Negative Arc (Weiland)
- **Disillusionment Arc** — character learns Truth, but it's painful (e.g., loss of innocence)
- **Fall Arc** — character clings to Lie despite Truth available
- **Corruption Arc** — character chooses Lie over Truth they once held

## Key Components of Any Arc
- **The Goal** — what the character consciously wants
- **The Lie / Misbelief** — false belief about self or world that blocks them
- **The Truth** — wisdom they need to embrace (or refuse)
- **The Need** — deeper, often unconscious desire
- **The Ghost / Wound** — backstory event that planted the Lie

## Arc Stages (mapped to Three-Act)
- **Act 1**: Lie + Want established; inciting incident challenges it
- **Act 2**: Series of failures while clinging to Lie; midpoint reveals Truth
- **Act 3**: Choice between Lie and Truth; climactic action proves chosen value

## Quality Criteria
- **Earned transformation** — change feels caused, not declared
- **Consistent characterization** — small choices align with internal state
- **Integration with plot** — arc and external events feed each other
- **Stakes match Lie** — what the character risks losing is meaningful
- **Final state mirrored against initial state** — visible transformation

## Other Arc Frameworks
- **Hero's Journey arc** (Campbell/Vogler) — descent + return
- **Christopher Booker's 7 Basic Plots** — each implies a character arc shape
- **Dan Harmon's Story Circle** — 8 beats, you/need/go/search/find/take/return/change
- **Fichte's Curve / Tragic arc** — descent, climax, no return
