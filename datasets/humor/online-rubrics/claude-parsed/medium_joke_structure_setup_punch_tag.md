# Medium: The Three-Part Joke

## Why Three Parts, Not Two
Most beginners think a joke is setup + punch. Pros think setup + punch + TAG. The tag is what separates a chuckle from sustained laughter, because it (a) extends the laugh, (b) demonstrates the writer can riff, and (c) reframes the punch one more time.

## Setup
- Should establish ONE wrong assumption the audience makes.
- Should be in the present tense.
- Should use the smallest number of concrete nouns possible.
- Should NOT contain words that telegraph the punch.
- Should leave the AUDIENCE to fill in the expected next sentence (so you can subvert it).

## Punchline
- Pivots on the wrong assumption.
- The pivot word goes LAST.
- Should re-use a word from the setup in a new sense if possible (the "double-meaning lock").
- Should not introduce information that wasn't latent in the setup.

## Tag
- A second beat off the SAME premise (not a new joke).
- Usually shorter than the punch.
- Heightens, contrasts, or comments on the punch.
- A great tag re-uses the punch's pivot word.

## The Multi-Tag Pattern
A masterful comic stacks tags 1, 2, 3 — each extending the laugh that's still in the room. Practical limit: 3 tags. After that, you're in a runner.

## Rubric for the Three-Part Joke
1. Setup: clear wrong assumption, present tense, no telegraphing.
2. Punch: pivots on a setup word, surprise word last.
3. Tag: same premise, different angle, shorter.
4. Total time on stage: under 30 seconds.
5. The tag gets at least 70% of the punchline's laugh.
6. The audience is still laughing when you start the next bit.
