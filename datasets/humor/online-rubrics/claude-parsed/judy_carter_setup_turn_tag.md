# Judy Carter — Setup / Turn / Tag

A second Judy Carter rubric: the basic joke anatomy.

## Three-Part Joke Structure

### 1. Setup
- The foundational element introducing the premise.
- Sets the stage for the audience.
- Establishes the scenario or "the normal."
- Creates anticipation.
- Should be **clear, concise, and grounded in relatability**.
- Guides listeners toward the punchline.

### 2. Turn (Punch)
- The unexpected twist.
- Pivots the meaning.
- Where the laugh happens.

### 3. Tag
- An additional punch line that doesn't need a new setup.
- Extends the original premise.
- Maximizes laughs from a single setup.

## Authentic Topic Sources
Personal experiences related to:
- Childhood
- Relationships
- Jobs
- Special challenges

These resonate more because they're relatable.

## Rubric
1. Is the setup clear, concise, relatable?
2. Is there a clean turn (twist)?
3. Are tags possible to extend?
4. Does the topic come from authentic experience?
5. Is the audience guided into a clear expectation before the turn?
