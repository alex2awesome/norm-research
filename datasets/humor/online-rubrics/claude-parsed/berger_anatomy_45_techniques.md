# Berger — 45 Humor Techniques (An Anatomy of Humor)

A comprehensive content-analytic taxonomy across all media. 45 techniques in 4 categories.

## Four Basic Categories
1. **Language** (verbal humor)
2. **Logic** (ideational humor)
3. **Identity** (existential humor)
4. **Action** (physical / nonverbal humor)

## The 45 Techniques

### Language Category
1. Allusion
2. Bombast
3. Definition
4. Exaggeration (verbal)
5. Facetiousness
6. Insults
7. Infantilism
8. Irony
9. Misunderstanding (linguistic)
10. Over-literalness
11. Puns / Wordplay
12. Repartee
13. Ridicule
14. Sarcasm
15. Satire

### Logic Category
16. Absurdity
17. Accident
18. Analogy
19. Catalogue
20. Coincidence
21. Comparison
22. Disappointment
23. Ignorance
24. Mistakes
25. Repetition
26. Reversal
27. Rigidity
28. Theme and Variation
29. Unmasking

### Identity Category
30. Before/After
31. Burlesque
32. Caricature
33. Eccentricity
34. Embarrassment
35. Exposure
36. Grotesque
37. Imitation
38. Impersonation
39. Mimicry
40. Parody
41. Scale (gigantism/diminution)
42. Stereotype

### Action Category
43. Chase
44. Slapstick
45. Speed

## Significance
- Comprehensive and mutually exclusive classification.
- Derived from content analysis of humor in many media.
- Useful for tagging any humor specimen.

## Rubric (using Berger Taxonomy)
1. Which of the 45 techniques does the joke employ?
2. Is more than one technique combined?
3. Which category dominates (Language/Logic/Identity/Action)?
4. Is the technique used freshly or formulaically?
5. Does the technique fit the topic / audience?
