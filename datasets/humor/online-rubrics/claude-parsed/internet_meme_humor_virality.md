# Internet Memes — Humor Structure and Virality

## Most Prevalent Humor Types in Memes
- Sarcasm (most common)
- Silliness
- Self-defeating (most effective for virality)
- Comparison
- Personification
- Exaggeration
- Pun
- Surprise

## What Makes Memes Spread (Virality Factors)
1. **Humor** itself
2. **Intertextuality** — blending different cultural references.
3. **Juxtaposition** — incongruous elements.
4. **Cute / emotionally arousing** content.
5. **Dopamine-triggering** laughter.

## Structural Elements

### Multimodal
- Image + superimposed text.
- The image-text relationship IS the joke.
- Multiple layers of meaning embedded.
- Advanced inferential strategies required.

### Context-Dependence
- Reward fast recognition + cultural fluency.
- Outsiders miss the joke.
- Insiders get it instantly.
- Inside-joke effect amplifies sharing.

### Format Templates
- "Distracted Boyfriend"
- "Drake approving/disapproving"
- "Two Buttons"
- "Galaxy Brain"
- Each template carries pre-loaded meaning.

## Modern Meme Trends
- **Absurdist / surreal**: lack setup-punchline; randomness itself is funny.
- **Layered irony**: ironic memes about ironic memes.
- **Gen Z humor**: deliberately incoherent, post-ironic.
- **Format mutation**: templates evolve weekly.

## Rubric for a Funny Meme
1. Does it use a recognizable format/template?
2. Does the image-text combination create incongruity?
3. Is there cultural reference (intertextuality)?
4. Does it reward in-group fluency?
5. Is it shareable (compact, instantly readable)?
