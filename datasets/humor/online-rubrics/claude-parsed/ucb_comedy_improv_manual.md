# UCB Comedy Improvisation Manual

By Matt Besser, Ian Roberts, Matt Walsh (2013)

## The Game of the Scene
The central concept of UCB long-form improv comedy.

### Process
1. **Yes-And** to establish a Base Reality
2. **First Unusual Thing (FUT)**: notice the first unusual element in the scene
3. **Frame** the unusual thing — call it out and acknowledge it
4. **Agree** on the unusual thing as both partners
5. **Develop** it into a patterned, repeatable Game

### Heightening the Game
- Each iteration of the game should escalate
- "If this unusual thing is true, what else is true?"
- Use logical extensions of the unusual premise
- Avoid simply repeating — heighten

## Key Concepts
- **Base Reality**: the grounded, normal world of the scene
- **First Unusual Thing**: the deviation from base reality
- **Game**: the repeatable pattern of unusual behavior
- **Heightening**: escalating the game with each beat
- **Justification**: explaining why the unusual thing makes sense
- **Pattern Recognition**: spotting and extending the game

## Long Forms
- **The Harold**: classic long-form structure
- **The Movie**: cinematic long-form

## Rubric for Evaluating an Improv Scene
1. Is there a clear Base Reality?
2. Was the First Unusual Thing identified?
3. Is the game framed and agreed upon?
4. Does each beat heighten the game logically?
5. Are the players "if this is true, then what else..." reasoning?
6. Is the unusual thing being explored, not just repeated?
