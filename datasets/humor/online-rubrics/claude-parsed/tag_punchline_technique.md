# Tags / Tag Lines in Comedy

## Definition
A tag is the third element of a joke — any laugh line **after the original punch line**. A tag is an additional short punchline immediately following a punchline (or another tag) that does **not require a new setup**.

## Joke Structure with Tags
- Standard: setup → punchline
- With tags: setup → punchline → tag → tag → tag …

## Functions of a Tag
A tag line should do one of the following:
1. Take the logic of the premise further/deeper.
2. Offer an opinion or angle from another source/perspective.
3. Reflect/respond to the audience's reaction.

## Why Tags Matter
- Build the funniness of the joke.
- Maximize laughs from a single setup.
- Mark a more sophisticated/experienced comedian.
- Show the comedian "thinking" about their own joke.

## Optional
- Tags are optional; a joke can have many tags or none.

## Rubric for Evaluating a Tag
1. Is the tag short (no new setup required)?
2. Does it extend the same premise?
3. Does it land its own laugh (not just repeat)?
4. Is it placed close enough in time to ride the original laugh?
5. Does it take the premise further (escalate)?
