# WikiHow: How to Write a Joke

## Method 1 — Find the Funny Idea
1. Brainstorm topics from your daily life: airports, dating, parents, jobs.
2. Identify an opinion or strong feeling about the topic — anger, confusion, frustration are funniest.
3. Make a list of associations: for each topic write 10–20 words/phrases connected to it.
4. Look at the LIST for unexpected pairings or absurd contradictions.

## Method 2 — Build the Setup and Punchline
1. The SETUP creates an expectation. Use plain, direct language.
2. The PUNCHLINE breaks the expectation. The break should be both surprising and inevitable.
3. The "reinterpretation" rule: the punchline should make the audience reread the setup in a new light.
4. Place the funniest WORD at the very end of the punchline.

## Method 3 — Use Joke Formulas
1. The Triple: A, B, C — where C subverts the AB pattern.
2. The List: list-of-three with the third item being absurd.
3. The Comparison: "X is like Y" with an unexpected Y.
4. The Reframe: a familiar thing described as if alien.
5. The Misdirection: setup leads one direction, punchline goes elsewhere.

## Method 4 — Edit the Joke
1. Cut every word that isn't essential. If you can remove it and still understand, remove it.
2. Replace soft words with hard, specific ones (a "dog" beats "a small mammal"; "Buick" beats "car").
3. Test it on a friend; if you have to explain, rewrite.
4. Time the joke — most one-liners should land in under 8 seconds.

## Rubric for "Is This Joke Done?"
1. Does the setup raise a single, clear expectation?
2. Does the punchline subvert that expectation?
3. Is there a "second meaning" that makes the audience reread the setup?
4. Is the funniest word at the end?
5. Is every word load-bearing?
6. Does it land in under 10 seconds?
7. Does someone you trust laugh without explanation?
