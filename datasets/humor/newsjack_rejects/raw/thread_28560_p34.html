Welcome to the forums!

Quote: Mike Yeoman @ October 21 2013, 10:03 PM BST

I know it probably doesn't make much difference as to whether on not they are accepted but I just wondered what people on these forums tend to do?

View original

I tend to submit in Word document file format (as opposed to a pure text file) and keep to 12pt Arial, but I drop the character name and 4cm indent. If it needs a character/accent I usually stick it in parentheses at the start of the line.

Make sure you have a header with your name (email address) and file title (something like 1-liners). And I usually sort the 1-liners/JackApps/introductions/corrections/etc into rough groupings with a (non formatted, usually I use about 9pt centred emboldened Arial) title - e.g. "Probably 1-liners/Jack Apps"

I don't think they're overly fussy with format of 1-liners, but having your name/email in the header and using 12pt Arial is probably about the minimum.

Hope this makes sense/helps.
