Might be an idea. The script editor usually writes the opening bit for Justin at the very end, when everything's all done, so it allows it to be ultra-topical (ie Wed morning if poss) so you might be doing yourself a disservice by using stuff not that topical.

That said, if it's very funny they will use it. You could try write them as introductions to sketches. I mean, granted, you don't know which sketches they will use, but if you're confident enough of the material (and, to reiterate, it's funny) it's an option.
