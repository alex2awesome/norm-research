# Caple — Photojournalism: Visual News Values

Helen Caple's framework for visual newsworthiness in press photographs. Builds on her DNVA work with Bednarek.

## Visual News Values (Caple)

Two factors shape news values in images:
1. **Contextualization** — denotative meaning of represented participants (who is shown, what is happening)
2. **Technical considerations** — connotative meaning via shutter speed, lens, angle

## 5 Photographic News Values (Craig)

1. **Reference to elite persons** — Famous faces
2. **Composition** — Rule of thirds, framing, balance
3. **Personalization** — Individual human face
4. **Negativity** — Suffering, damage
5. **Conflict / Dramatization** — Tension visible

## Image-Inherent News Factors (newer research)

Selection criteria determining whether images are "worth publishing":

1. **Damage** — Visible destruction
2. **Violence / Aggression** — Action shots
3. **Controversy** — Provocative subjects
4. **Celebrities** — Famous faces
5. **Unexpectedness** — Surprising tableaus
6. **Emotions** — Visible affect
7. **Execution and technique** — Photographic craft
8. **Sexuality / Eroticism** — Sexual imagery (more in tabloid)

## Aesthetic News Value (Caple's Addition)

- Press photographs can construe news events as **aesthetically appealing**
- Beauty itself becomes a news value
- Balance, color, composition draw attention
- "Picture-worthy" moments

## Discursive Construction

Visual news values constructed through:
- **Content** — what is included in the image
- **Camera technique** — how the image is captured
- **Caption** — verbal anchoring
- **Layout** — placement on page

## Implicit Visual Newsworthiness Criteria

- **Decisive moment** capture
- **Faces and emotion**
- **Dramatic action**
- **Beauty and composition**
- **Documentary truth**
- **Iconic potential** (could become symbolic)
- **Conflict visualization**
- **Famous person**
- **Aesthetic quality**
