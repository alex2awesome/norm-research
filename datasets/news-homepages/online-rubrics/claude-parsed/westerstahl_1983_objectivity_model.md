# Westerståhl (1983) - Objective News Reporting

Jörgen Westerståhl's canonical analytic decomposition of "objectivity" into measurable sub-dimensions. Built from Westerståhl's eight major Swedish objectivity studies of the 1970s and codified the schema that has anchored European objectivity research ever since. Published in *Communication Research* 10(3): 403–424.

The contribution: Objectivity is not a single norm but a composite. The Westerståhl schema specifies what each component requires — and therefore what an objective news selection system must produce.

## The Westerståhl Objectivity Schema

```
                       OBJECTIVITY
                            |
              -------------------------------
              |                             |
         FACTUALITY                    IMPARTIALITY
              |                             |
        ---------------          --------------------------
        |             |          |                        |
      TRUTH      RELEVANCE     BALANCE/             NEUTRAL
                              NON-PARTISANSHIP    PRESENTATION
```

## Components

### Factuality

1. **Truth** - The story should be accurate, verifiable, and free of fabrication. Operationalized as correspondence between report content and verifiable facts.

2. **Relevance** - The story should select information that matters to the public — i.e., that bears on important social issues, decisions, or events. Trivial facts can be true but irrelevant; relevance is part of objectivity.

### Impartiality

3. **Balance / Non-Partisanship** - Equal treatment of competing parties or perspectives. Neither side systematically advantaged in airtime, source counts, or favorable framing.

4. **Neutral Presentation** - The framing, tone, language, and visual treatment should not advantage any side. Even balanced quotes can be undermined by tilted framing.

## Operational News-Selection Criteria Derived from the Model

1. **Verifiability Premium** - Items whose facts can be independently checked are more reportable (e.g., documented events > rumored events).

2. **Relevance Filter** - True but trivial items are demoted; the relevance test must be passed.

3. **Source Balance** - Stories are selected partly because they admit balanced sourcing (e.g., a partisan dispute with clear two sides is easier to report objectively than a one-voice condemnation).

4. **Quote Symmetry** - In selection and editing, quote counts should match.

5. **Tonal Neutrality** - Stories framed in non-loaded language are preferred to stories that require taking a side.

## Implications for Newsworthiness

- **Decomposition advantage**: The four components can be measured separately, making the model usable as a quality-audit tool — a homepage rubric can check stories on each axis.

- **Truth ≠ relevance**: An item can be true but irrelevant (much trivia); relevance is a substantive selection criterion within objectivity, not a separate criterion.

- **Why "balance" is structural**: Balance is required for objectivity in this schema; reporters select stories partly because they admit balanced treatment. Stories without two clear sides are systematically under-covered or reframed.

- **Cross-national applicability**: Used widely in European media-quality audits (Sweden, Netherlands, Germany) — provides a comparative reference point for US objectivity discussions (Schudson 2001).
