# Coded vs articulated metrics — seam-theory synthesis (2026-08-25)

Produced during the chandra v2 campaign in answer to the "complexity threshold"
question; grounded in the paper-5 metric-seam proposal's committed apparatus.

1. **Threshold is substrate-relative.** The clean statement is description length
   relative to an executor's primitive basis. Coded metric = program over
   enumerable primitives; articulated metric = prompt program over a judge's
   LEARNED predicates. M crosses the seam when K_code(M) exceeds budget while
   K_judge(M | weights) stays small — the prompt only INDEXES a capability the
   judge embodies. "Complexity passes a threshold" = "the two description-length
   curves cross," and the crossing is executor-indexed (capability-graded
   function wall: regex -> parser -> embedder -> judge).
2. **One-sided decidability (proposal §3.4).** Codability certifies positively
   (code witness + kappa-faithfulness + CF-validity + non-inferiority).
   "Needs text" is only bounded non-discovery within a frozen program class +
   budget. The seam is an empirical frontier maintained by certificates, not a
   theorem-given line — paper text must not imply a provable transition.
3. **The wall is 2-D**: channel = extractor ∘ predicate; rule-thickness
   ("condescending") vs input-thickness ("locate the reveal"). Only joint
   thinness compiles. Legal-formalization lineage converged on the same split:
   elements compile, gestalt stays out.
4. **Not informational — functional + certificational.** DPI: computation ops
   add zero construct information; they widen executor bound B_E, never the
   ceiling I(M;X). Code buys a replayable exact certificate; text buys access to
   predicates code can't compactly realize, at the price of judge-relative
   (statistical, frozen-judge) semantics. Tightening-lemma slogan: migration
   confines the uncertified residual to the LLM share — the seam is where the
   certificate is tight.
5. **Empirically a profile, not a binary**: kappa_e(L) 5 regimes; certifying
   tool-dominant hybrids (a86 rho .895 P=1.00) coexist with A-layer-only
   constructs (a105 scoped .398). Same wall recurs one level up:
   MECH compiles, CRAFT partially, TASTE needs scale — the V < A < T ladder
   (chandra: V ~.55, A ~.58-.79, T ~.85-.91). Coded->articulated is the first
   seam; articulated->dense-weights the second; T−VA is its measured width.
6. **Owed before quotable as theory**: U2 extension over Omega×{code,llm};
   tightening lemma derivation; no growth theorem exists (min code length
   super-linear in compositionality vs flat prompt length) — currently filled
   empirically by the certified 160-metric survey.
